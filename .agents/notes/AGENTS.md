# AGENTS.md — Agent Notes

Agent Notes are effectively RFCs written by agents and maintainers: durable proposals and decision records that preserve rationale, alternatives, consequences, and required verification. Follow the documentation standard ([docs/AGENTS.md](../../docs/AGENTS.md)) and the [Agent Note rules](README.md).

**Every new Agent Note triggers a supersession check.** Search the active tree for older notes covering the same decision or mechanism, classify any full or partial supersession, cross-link partial ones, and consolidate fully superseded implemented notes only after preserving their unique rationale and repairing every inbound link.

Files under [archived/](archived/AGENTS.md) are frozen historical snapshots: never edit them or treat them as current authority.
