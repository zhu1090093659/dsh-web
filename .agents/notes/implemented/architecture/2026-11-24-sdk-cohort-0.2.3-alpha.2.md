# Agent Note: SDK cohort 0.2.3-alpha.2

Status: implemented

Partially supersedes [2026-11-14 SDK cohort 0.2.2-rc.3](2026-11-14-sdk-cohort-0.2.2-rc.3.md) on the SDK baseline cohort pin, Node.js runtime floor, client stylesheet lifecycle, official bundle snapshot, Markdown fence class contract, and subagent allowlist reading.

## Problem

Upstream `@deepseek-ai/dsh` advanced to `0.2.3-alpha.2`, bringing runtime, build, and bundle-roster breaking changes across five repository contracts while raising the host Node.js floor to `^24.22.3 || >=26.13.1`:

- Official UI renderer `0.2.3-alpha.2` replaces ad-hoc bundle-body DOM `<style>` writes with `DocumentStyles`, reading deferred `meta: () => ({ stylesheets })` declarations from `window.__ModuleLoader__.load({ id, factory, meta })` (`@deepseek-ai/dsh-client-ui-renderer`).
- Upstream removed `ui-settings-plugins` and `ui-settings-plugin-inventory` from `dsh-web-app`; leaving the bare `- id: ui-settings-plugins` (`disabled: true`) patch row in `dsh-plugin-manager` (and `dsh-web-all`) triggers `patch: entry "ui-settings-plugins" not found` warnings on boot.
- Upstream changed CSS Modules class generation to `[hash]_[local]` with no trailing underscore, breaking `dsh-diagrams`'s `_infostring_` and `_language_` substring hooks.
- Upstream stopped appending `subagent/model-selection-policy` session events and instead exposes `ctx.get('subagentModelSelection').allowedRoutes()`, leaving `dsh-liangshen`'s `subagent-routes` preset guard unread when the live service changes or clears routes.
- Node.js `v26.13.1` exposes a configurable `globalThis.localStorage` accessor returning `undefined` without `--localstorage-file`, breaking jsdom suites such as `dsh-plugin-manager` that lacked `shared/vitest.setup.ts`.

## Decision

The repository's SDK baseline, host floor (`>=0.2.3-alpha.2`), Node.js floor (`^24.22.3 || >=26.13.1`), `@deepseek-ai/cordis` (`~4.2.0-alpha.1`), `@deepseek-ai/schemastery` (`~3.20.0-alpha.1`), CI/release pins, workspace overrides, README badges, and root lockfile advance together to `@deepseek-ai/dsh@0.2.3-alpha.2` (`host-sdk:check` pins 216/216 workspace entries against the 349-package host tree). Family package versions stay at `0.4.21` and the four satellite repositories remain unedited and at their pinned commits.

## Compatibility adaptations & adopted contracts

- **Adopt official `DocumentStyles` stylesheets (`shared/tsdown.client.ts`)**: `dsh-css-modules-inline` compiles each `.module.css` file deterministically with `[hash]_[local]` into an in-memory per-bundle map keyed by repo-relative path (`moduleSideEffects: 'no-treeshake'`) and emits `meta: () => ({ stylesheets: { [fileId]: { text: () => css } } })` through `outputOptions.footer(chunk)` rather than injecting `<style data-plugin-css>` inside `factory`. Dynamic runtime adaptation styles in `packages/dsh-remote-web-ui/src/client/mobile-adapt.ts` do not ride CSS Modules and stay untouched.
- **Drop retired `ui-settings-plugins` override (`packages/dsh-plugin-manager`, `packages/dsh-web-all`, `scripts/aggregate.mjs`)**: Remove the `- id: ui-settings-plugins` bare patch row from `packages/dsh-plugin-manager/cordis.patch.yml` and regenerate `packages/dsh-web-all/cordis.patch.yml` via `node scripts/aggregate.mjs`. Refresh `OFFICIAL_ROW_IDS` in `packages/dsh-plugin-manager/tests/bundle-row-id.spec.ts` to the 211 rows shipped by `0.2.3-alpha.2` `dsh-base` and `dsh-web-app`, update `scripts/aggregate.test.mjs` to exercise bare patch forwarding via a synthetic fixture while asserting `ui-settings-plugins` remains absent, and wire `../../shared/vitest.setup.ts` into `packages/dsh-plugin-manager/vitest.config.ts` so Node 26 jsdom suites get `MemoryStorage`.
- **Update CSS Modules fragments (`packages/dsh-diagrams`)**: Change `INFOSTRING_CLASS_FRAGMENT` and `LANGUAGE_CLASS_FRAGMENT` in `packages/dsh-diagrams/src/core/contract.ts` to `'_infostring'` and `'_language'`, matching both legacy `_<local>_<hash>` and `0.2.3-alpha.2` `<hash>_<local>` class names.
- **Read live `subagentModelSelection` service (`packages/dsh-liangshen`)**: `presets/liangshen/subagent-routes.mjs` keeps `inject = ['tools']` and reads `ctx.get('subagentModelSelection')` live per guarded delegation call. When mounted, `allowedRoutes()` is authoritative (returning `undefined` allows directly without consulting stale session events, and throwing fails open so official settings diagnostics surface); only when the service is absent does the guard fall back to `subagent/model-selection-policy` events.
- **Workspace extensions and exclusions (`pnpm-workspace.yaml`, `package.json`)**: Add `@deepseek-ai/dsh-launch-environment` (`^0.2.3-alpha.2`) to root `devDependencies` as the required peer host face imported by `dsh-credentials@0.2.3-alpha.2`, bump `overrides` and `packageExtensions` keys to `0.2.3-alpha.2` (adding `@deepseek-ai/dsh-util-file-drag: 0.2.3-alpha.2` and `0.2.3-alpha.2` transitive deps on `@deepseek-ai/dsh-client-ui-primitives`), and reconcile `minimumReleaseAgeExclude` 1:1 against the 61 resolved `@deepseek-ai/*` lockfile entries (preserving `cosmokit@1.9.0` and `schemastery@3.19.0` resolved by unbumped satellite packages while removing unused entries).

## Native-first overlap review

- **Keep `packages/dsh-remote-web-ui` as a standalone recorded exception**: Official `dsh-client-remote-connection` covers QR/link generation and device pairing only; it does not support custom bind-address management, cloudflared tunneling, or the LAN HTTP/WebSocket forwarder, and `dsh-remote-web-ui` is already excluded from `dsh-web-all`. Replacing it with `remote-connection` would drop required remote-access capabilities, so `dsh-remote-web-ui` stays standalone on its native `0.2.3-alpha.2` host admission/entry seams (`admit`, `webserver/entry-url`, `WebRoute.auth`).
- **Remove manual CSS-module DOM injection**: Replaced `shared/tsdown.client.ts`'s inline `<style data-plugin-css>` emitter with the official `DocumentStyles` `meta().stylesheets` pipeline so uninstall/reload/conflict handling belongs to the host renderer.

## Alternatives considered

- Keep the manual `<style data-plugin-css>` injector inside `shared/tsdown.client.ts` instead of migrating to `meta().stylesheets`: rejected because official `DocumentStyles` owns stylesheet deduplication, ordering, and hot-unload cleanup by `[data-plugin][data-path]`, and retaining a parallel injector duplicates style lifecycle outside the renderer.
- Add `subagentModelSelection` to `export const inject` in `packages/dsh-liangshen/presets/liangshen/subagent-routes.mjs`: rejected because hard-injecting an optional host service would prevent the preset row from mounting on hosts or test compositions that omit `subagent-model-selection-settings`.
- Bump `@linxin666/*` package versions or modify the four satellite repositories in the same change: rejected by explicit task authorization; satellite repositories remain at `0.4.21` and will align on their own release cycle.

## Consequences

- Committed client bundles (`packages/dsh-market/lib`, `packages/dsh-web-all/lib`) and `scripts/lib-artifact-fingerprints.json` carry the `0.2.3-alpha.2` builds and stylesheet metadata without mutating `document.head` inside `factory`.
- Local `dsh --version` and workspace `node_modules/@deepseek-ai` are aligned on `@deepseek-ai/dsh@0.2.3-alpha.2` under Node.js `v26.13.1`, while any pre-existing running `dsh-web.service` process and its `~/.dsh/profiles/web` install require an explicit operator restart and profile reinstall outside this session.
- Pre-existing `M satellites/dsh-community-plugins` state in the operator checkout and all four satellite repositories stay untouched.
