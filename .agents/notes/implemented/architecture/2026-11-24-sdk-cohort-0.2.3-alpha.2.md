# Agent Note: SDK cohort 0.2.3-alpha.2

Status: implemented

Partially supersedes [2026-11-14 SDK cohort 0.2.2-rc.3](2026-11-14-sdk-cohort-0.2.2-rc.3.md) on the SDK baseline cohort pin, Node.js runtime floor, client stylesheet lifecycle, official bundle snapshot, Markdown fence rendering contract, route auth defaults, host auth/slot integrations, remote web UI retirement, and subagent/MCP/SQLite compatibility.

## Problem

Upstream `@deepseek-ai/dsh` advanced to `0.2.3-alpha.2`, raising the host Node.js floor to `^24.22.3 || >=26.13.1` and changing multiple host, client, build, and bundle-roster contracts:

- Official UI renderer `0.2.3-alpha.2` replaces ad-hoc bundle-body DOM `<style>` writes with `DocumentStyles`, reading deferred `meta: () => ({ stylesheets })` declarations from `window.__ModuleLoader__.load({ id, factory, meta })` (`@deepseek-ai/dsh-client-ui-renderer`).
- `@deepseek-ai/dsh-host-webserver` defaults `WebRoute.auth` to `'authenticated'`, so plugin routes that enforce their own loopback or pairing guard must explicitly declare `auth: 'anonymous'`.
- Upstream removed `ui-settings-plugins` and `ui-settings-plugin-inventory` from `dsh-web-app` and added native version/update controls (`section[data-plugin-versions]`) to plugin detail pages.
- Upstream changed CSS Modules class generation to `[hash]_[local]` with no trailing underscore and unified code blocks under `.md-code-block`, breaking `_<local>_` substring hooks in `dsh-diagrams`, `dsh-web-all`, and several skins in `dsh-skins`.
- Upstream introduced first-party slots, services, and backends that overlap or interact with family plugins: `conversation.chat.markdown.fence`, `settings.remoteConnection.extensions`, `conversation.session.panel.environment.row`, `ctx.deepseekAuth`, `dsh-home-paths` (`$DSH_AGENTS_HOME`), `@deepseek-ai/dsh-plugin-market-index` Format 1, MCP on-demand tool loading (`mcp__<server>__load_tools` + `mcp:<server>:tools`), official SQLite session persistence (`sessions/.segments/sessions.sqlite`), live `subagentModelSelection.allowedRoutes()`, and `@deepseek-ai/dsh-client-remote-connection`.
- Node.js `v26.13.1` exposes a configurable `globalThis.localStorage` accessor returning `undefined` without `--localstorage-file`, breaking jsdom suites that lacked `shared/vitest.setup.ts`.

## Decision

The monorepo and all four satellite repositories (`satellites/dsh-skins`, `satellites/dsh-pet`, `satellites/dsh-presets`, `satellites/dsh-community-plugins`) align on `@deepseek-ai/dsh@0.2.3-alpha.2`, host floor `>=0.2.3-alpha.2`, Node.js floor `^24.22.3 || >=26.13.1`, `@deepseek-ai/cordis@~4.2.0-alpha.1`, `@deepseek-ai/schemastery@~3.20.0-alpha.1`, and the official `DocumentStyles` client build pipeline. Family package versions stay at `0.4.22` pending an explicit release. `packages/dsh-remote-web-ui` is retired and removed from the workspace because official `@deepseek-ai/dsh-client-remote-connection` covers browser pairing and approval while `@linxin666/dsh-remote-bridge` covers tunneling and the iOS bridge.

## Compatibility adaptations & adopted contracts

- **Adopt official `DocumentStyles` stylesheets (`shared/tsdown.client.ts` across main repo and all 4 satellites)**: `dsh-css-modules-inline` compiles each `.module.css` file deterministically with `[hash]_[local]` into an in-memory per-bundle map keyed by repo-relative path (`moduleSideEffects: 'no-treeshake'`) and emits `meta: () => ({ stylesheets: { [fileId]: { text: () => css } } })` through `outputOptions.footer(chunk)` rather than injecting `<style data-plugin-css>` inside `factory`.
- **Explicit route auth and `0.2.2-rc.3` bridge cleanup**: Declare `auth: 'anonymous'` on all self-guarded routes in `dsh-agents`, `dsh-web-settings`, and satellites (`dsh-skins`, `dsh-pet`, `dsh-presets`). Remove temporary `AuthAwareWebRoute`/`AuthAwareUpgradeRoute`, `requestRejection`, and `authenticatedUrl` dual-cohort shims across packages, standardize on `connection.admit(request)` and `webserver/entry-url`, and extend `shared/host/pair-access.ts` (and `dsh-pet`'s copy) to admit official `connection.admit(request)` peers alongside loopback and legacy pairing cookies.
- **Migrate `dsh-diagrams` to `conversation.chat.markdown.fence`**: Optionally inject `slots` and register `MermaidFenceLayer` on `conversation.chat.markdown.fence` to render sanitized Mermaid SVG once streaming completes, falling back to `children` while streaming or on error. Keep the DOM observer only as a fallback for surfaces without `renderCode` (such as `DocumentPreview`) and skip code blocks inside `[data-slot="conversation.chat.markdown.fence"]` to avoid double rendering; keep `'_infostring'` and `'_language'` fragments compatible with `[hash]_[local]`.
- **Adapt `dsh-liangshen` to MCP on-demand loading and live subagent routes**: `presets/liangshen/paging.mjs` detects `mcp__<server>__load_tools` loaders and exempts those on-demand servers (both loader and loaded tools) from secondary paging while keeping eager MCP servers paged; `presets/liangshen/minimal-prompt.mjs` preserves `mcp:<server>:tools` catalog sections. `presets/liangshen/subagent-routes.mjs` reads `ctx.get('subagentModelSelection').allowedRoutes()` live with event-log fallback only when the service is absent.
- **Protect official SQLite sessions in `dsh-session-archive`**: `src/host/session-files.ts` skips the `.segments` directory during JSONL discovery and detects official SQLite-backed sessions via `sessions/.segments/sessions.sqlite` (`application_id = 0x44535043`, `user_version = 1`) and `.segments/<sha256>.json` route markers; `src/host/janitor.ts` refuses physical deletion of SQLite-managed sessions (`reason: 'missing-seam'`) before mutating archive state, workspace links, or lock directories.
- **Shrink `dsh-plugin-manager` detail UI and drop retired `ui-settings-plugins` patch**: Remove the `- id: ui-settings-plugins` patch row, refresh `OFFICIAL_ROW_IDS` to the 211 `0.2.3-alpha.2` rows, wire `shared/vitest.setup.ts` for Node 26 jsdom tests, and defer `PluginUpdatePatch` to the native `section[data-plugin-versions]` section when present (rendering only a compact restore strip when the package has a locally ignored version).
- **Adopt official auth, home paths, UI slots, and market index Format 1**:
  - `dsh-usage` and `dsh-remote-bridge` authorize official DeepSeek balance probes through `ctx.deepseekAuth.authorize(...)` first (falling back to existing credential resolution when absent), and `dsh-remote-bridge` adds `deepseek-account` wallet balance support.
  - `shared/host/dsh-home.ts` and `dsh-skill-explorer` align `$DSH_AGENTS_HOME` resolution (blank treated as unset, `~` expanded) with `@deepseek-ai/dsh-home-paths`.
  - `dsh-remote-bridge` registers its iOS / tunnel pairing panel in `settings.remoteConnection.extensions` (`id: 'remote-bridge-ios'`, `order: 20`).
  - `dsh-session-id` registers a copyable session-id row in `conversation.session.panel.environment.row` (`id: 'session-id'`, `order: 40`).
  - `scripts/market-build` emits `market/dist/manifest/plugin-market-index.json` conforming to `@deepseek-ai/dsh-plugin-market-index` Format 1 (validated by `parseMarketIndex`, including only entries with exact SemVer versions). Family packages contribute their `package.json` version through the workspace scan, and community entries contribute theirs through the index's `version` field, which `scanPlugins()` carries into `manifest/plugins.json`; every family entry inlines its package `icon.svg` as a `data:` URL; an entry with no exact version stays out of the index (the satellite note [2026-11-25-community-entry-versions-feed-plugin-market-index](../../../../satellites/dsh-community-plugins/.agents/notes/implemented/process/2026-11-25-community-entry-versions-feed-plugin-market-index.md) owns that field's contract).
- **Repair `[hash]_[local]` selectors**: Update `dsh-web-all`'s right-column probe to `[data-rightbar-col], [class*="detailsCol"]` and fix legacy `_<local>_` / `codeBlock` selectors in `satellites/dsh-skins` (`verdandi`, `crt-phosphor`, `lucy-nightsignal`, `equation-sea`, `endfield-baker`, `miku`, `diy-journal`), regenerating `src/reviewed-hooks.generated.ts`.
- **Workspace extensions and exclusions (`pnpm-workspace.yaml`, `package.json`)**: Carry `@deepseek-ai/dsh-launch-environment` and the newly consumed `0.2.3-alpha.2` SDK packages (`dsh-client-remote-connection`, `dsh-client-ui-chat`, `dsh-client-ui-session-panel`, `dsh-plugin-market-index`) in devDependencies, workspace `packageExtensions`, and `minimumReleaseAgeExclude` across the monorepo and all four satellites.

## Native-first overlap review

- **Retire and remove `packages/dsh-remote-web-ui`**: With operator confirmation, browser pairing, QR/link access, and approval are delegated to official `@deepseek-ai/dsh-client-remote-connection`, while tunnel/LAN relay and iOS protocol remain in `@linxin666/dsh-remote-bridge`. `packages/dsh-remote-web-ui` is removed from the repository, READMEs, publish inventory, and test/coverage baselines; `packages/dsh-web-all/aggregate.yml` keeps silent no-op `tombstones`/`retiredPlugins`/`shellNotes` entries so legacy user profiles do not fail on load.
- **Remove manual CSS-module DOM injection**: Replaced `shared/tsdown.client.ts`'s inline `<style data-plugin-css>` emitter with the official `DocumentStyles` `meta().stylesheets` pipeline across both the monorepo and the four satellite repositories.
- **Evaluate `@deepseek-ai/dsh-client-config` (`SyncedConfig`) and retain `configForms`**: Upstream `SyncedConfig` only pushes read-only top-level `Volatile` values from host to client and provides no write-back path; interactive settings cards continue to use official `configForms` / `settings-form.ts`.

## Alternatives considered

- Keep `packages/dsh-remote-web-ui` as a standalone recorded exception alongside official `dsh-client-remote-connection`: rejected after operator confirmation that official remote-connection covers browser access and `dsh-remote-bridge` covers tunneling and iOS relay, avoiding parallel pairing and auth surfaces.
- Keep the manual `<style data-plugin-css>` injector inside `shared/tsdown.client.ts`: rejected because official `DocumentStyles` owns stylesheet deduplication, ordering, and hot-unload cleanup by `[data-plugin][data-path]`.
- Synthesize placeholder `0.0.0` versions for community plugins in `plugin-market-index.json`: rejected because Format 1 feeds client update/install resolution, so only packages with an explicit valid SemVer version are emitted.
- Add `subagentModelSelection` or `slots` as required hard `inject` entries in `dsh-liangshen` / `dsh-diagrams`: rejected so trimmed hosts and standalone test compositions keep mounting cleanly with graceful fallbacks.

## Consequences

- Committed client bundles (`packages/dsh-market/lib`, `packages/dsh-web-all/lib`), `scripts/lib-artifact-fingerprints.json`, `packages/dsh-web-all/cordis.patch.yml`, and `market/dist/` (including `manifest/plugin-market-index.json`) reflect the `0.2.3-alpha.2` build outputs and retired `dsh-remote-web-ui` state.
- All four satellite repositories (`satellites/dsh-skins`, `satellites/dsh-pet`, `satellites/dsh-presets`, `satellites/dsh-community-plugins`) carry aligned `0.2.3-alpha.2` SDK/build/route fixes pushed to their own `origin/main`, with submodule gitlinks and `market/dist/` refreshed in `dsh-web`.
- Any pre-existing running `dsh web` service and `~/.dsh/profiles/web` install require an explicit operator restart and profile refresh outside this session.
