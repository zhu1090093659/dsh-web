# Agent Note: SDK cohort 0.2.3-alpha.2

Status: implemented

本笔记在 SDK 基线队列锁定、Node.js 运行时下限、客户端样式生命周期、官方内置包快照、Markdown 围栏渲染契约、路由默认鉴权、宿主鉴权与槽位接入、`dsh-remote-web-ui` 正式下线以及子代理/MCP/SQLite 兼容性方面部分取代 [2026-11-14 SDK cohort 0.2.2-rc.3](2026-11-14-sdk-cohort-0.2.2-rc.3.zh.md)。

## 问题

上游 `@deepseek-ai/dsh` 推进至 `0.2.3-alpha.2`，将宿主 Node.js 下限抬升至 `^24.22.3 || >=26.13.1`，并在宿主、客户端、构建和内置行清单上引入了多项契约变更：

- 官方 UI 渲染器 `0.2.3-alpha.2` 将包体内直接写入 DOM `<style>` 替换为 `DocumentStyles`，通过 `window.__ModuleLoader__.load({ id, factory, meta })` 读取延迟声明的 `meta: () => ({ stylesheets })`（`@deepseek-ai/dsh-client-ui-renderer`）。
- `@deepseek-ai/dsh-host-webserver` 将 `WebRoute.auth` 默认收紧为 `'authenticated'`，自行实施 loopback 或配对守卫的插件路由必须显式声明 `auth: 'anonymous'`。
- 上游从 `dsh-web-app` 移除了 `ui-settings-plugins` 与 `ui-settings-plugin-inventory`，并在插件详情页提供了原生版本与更新区（`section[data-plugin-versions]`）。
- 上游将 CSS Modules 类名生成改为无尾随下划线的 `[hash]_[local]`，并将代码块统一为 `.md-code-block`，导致 `dsh-diagrams`、`dsh-web-all` 与 `dsh-skins` 中多套皮肤的 `_<local>_` / `codeBlock` 选择器失效。
- 上游新增了多项与家族插件交互或重叠的官方能力：`conversation.chat.markdown.fence`、`settings.remoteConnection.extensions`、`conversation.session.panel.environment.row`、`ctx.deepseekAuth`、`dsh-home-paths`（`$DSH_AGENTS_HOME`）、`@deepseek-ai/dsh-plugin-market-index` 格式 1、MCP 按需加载工具（`mcp__<server>__load_tools` 与 `mcp:<server>:tools`）、官方 SQLite 会话持久化（`sessions/.segments/sessions.sqlite`）、实时 `subagentModelSelection.allowedRoutes()` 服务，以及 `@deepseek-ai/dsh-client-remote-connection`。
- Node.js `v26.13.1` 在未传入 `--localstorage-file` 时暴露了返回 `undefined` 的可配置 `globalThis.localStorage` getter，使未接 `shared/vitest.setup.ts` 的 jsdom 测试套运行失败。

## 决策

本主仓与全部四个卫星仓（`satellites/dsh-skins`、`satellites/dsh-pet`、`satellites/dsh-presets`、`satellites/dsh-community-plugins`）统一对齐至 `@deepseek-ai/dsh@0.2.3-alpha.2`、宿主下限 `>=0.2.3-alpha.2`、Node.js 下限 `^24.22.3 || >=26.13.1`、`@deepseek-ai/cordis@~4.2.0-alpha.1`、`@deepseek-ai/schemastery@~3.20.0-alpha.1` 以及官方 `DocumentStyles` 客户端构建管线。家族包版本维持当前 `0.4.22`，待显式发版流程再统一推进。正式整包下线并移除 `packages/dsh-remote-web-ui`，浏览器配对与审批改由官方 `@deepseek-ai/dsh-client-remote-connection` 承接，公网/局域网隧道中继与 iOS 协议继续由 `@linxin666/dsh-remote-bridge` 承接。

## 兼容适配与官方契约采用

- **采用官方 `DocumentStyles` 样式表契约（主仓及全部四个卫星仓同步 `shared/tsdown.client.ts`）**：`dsh-css-modules-inline` 使用 `[hash]_[local]` 确定性编译每个 `.module.css` 文件并按仓库相对路径键入内存映射（`moduleSideEffects: 'no-treeshake'`），通过 `outputOptions.footer(chunk)` 发出 `meta: () => ({ stylesheets: { [fileId]: { text: () => css } } })`，不再在 `factory` 内手动插入 `<style data-plugin-css>` 标签。
- **路由鉴权显式化与 `0.2.2-rc.3` 过渡桥接清理**：为 `dsh-agents`、`dsh-web-settings` 及卫星仓 `dsh-skins`、`dsh-pet`、`dsh-presets` 的全部自守卫路由显式声明 `auth: 'anonymous'`；清理各包中临时性的 `AuthAwareWebRoute`/`AuthAwareUpgradeRoute`、`requestRejection` 与 `authenticatedUrl` 回退代码，统一使用 `connection.admit(request)` 与 `webserver/entry-url`，并扩展 `shared/host/pair-access.ts`（含 `dsh-pet` 副本）使官方 `connection.admit(request)` 准入的远程浏览器同样可通过访问守卫。
- **将 `dsh-diagrams` 迁至官方 `conversation.chat.markdown.fence` 槽位**：可选注入 `slots` 并在 `conversation.chat.markdown.fence` 注册 `MermaidFenceLayer`，流式输出期间原样返回 `children`，落定后渲染消毒 SVG，出错自动回退；DOM 观察器显式跳过 `[data-slot="conversation.chat.markdown.fence"]` 内代码块以防双重渲染，仅作为 `DocumentPreview` 等尚未透传 `renderCode` 表面的兜底，并保持 `'_infostring'` 与 `'_language'` 片段兼容 `[hash]_[local]`。
- **适配 `dsh-liangshen` 的 MCP 按需加载与实时子代理路由服务**：`presets/liangshen/paging.mjs` 自动识别 `mcp__<server>__load_tools` 加载器并放行按需 MCP 服务器的加载器与已加载工具，不与官方按需加载冲突（`eager` MCP 仍按原逻辑分页）；`presets/liangshen/minimal-prompt.mjs` 保留 `mcp:<server>:tools` 目录提示段。`presets/liangshen/subagent-routes.mjs` 保持实时读取 `ctx.get('subagentModelSelection').allowedRoutes()`，仅当服务缺失时回退事件日志。
- **在 `dsh-session-archive` 保护官方 SQLite 会话后端**：`src/host/session-files.ts` 在 JSONL 发现阶段跳过 `.segments` 目录，并通过 `sessions/.segments/sessions.sqlite`（`application_id = 0x44535043`、`user_version = 1`）与 `.segments/<sha256>.json` 路由标记识别官方 SQLite 托管会话；`src/host/janitor.ts` 在修改归档标记、工作区链接或磁盘目录前拒绝删除 SQLite 托管会话（返回 `reason: 'missing-seam'`）。
- **收缩 `dsh-plugin-manager` 重复详情页 UI 并移除退役的 `ui-settings-plugins` 补丁行**：删除 `- id: ui-settings-plugins` 裸补丁行，将 `OFFICIAL_ROW_IDS` 刷新为 `0.2.3-alpha.2` 的 211 个行 id，接入 `shared/vitest.setup.ts` 兼容 Node 26 jsdom，并让 `PluginUpdatePatch` 在检测到官方原生 `section[data-plugin-versions]` 时默认退让（仅在存在本地已忽略版本时展示精简恢复条）。
- **接入官方鉴权、路径规范、UI 槽位与市场索引格式 1**：
  - `dsh-usage` 与 `dsh-remote-bridge` 优先经 `ctx.deepseekAuth.authorize(...)` 为官方余额探测鉴权（未挂载时回退既有凭证路径），`dsh-remote-bridge` 同步补齐 `deepseek-account` 钱包余额查询。
  - `shared/host/dsh-home.ts` 与 `dsh-skill-explorer` 对齐 `@deepseek-ai/dsh-home-paths` 的 `$DSH_AGENTS_HOME` 解析规则（空白视作未设、展开 `~`）。
  - `dsh-remote-bridge` 将 iOS / 隧道配对面板挂载至官方 `settings.remoteConnection.extensions` 槽位（`id: 'remote-bridge-ios'`，`order: 20`）。
  - `dsh-session-id` 将可一键复制的会话 ID 行挂载至官方 `conversation.session.panel.environment.row` 槽位（`id: 'session-id'`，`order: 40`）。
  - `scripts/market-build` 新增符合 `@deepseek-ai/dsh-plugin-market-index` 格式 1 的 `market/dist/manifest/plugin-market-index.json`（经官方 `parseMarketIndex` 校验，仅收录具备精确 SemVer 版本的条目）。
- **修复 `[hash]_[local]` 失效选择器**：将 `dsh-web-all` 的右侧栏探测更新为 `[data-rightbar-col], [class*="detailsCol"]`，并修复 `satellites/dsh-skins` 中 7 套皮肤（`verdandi`、`crt-phosphor`、`lucy-nightsignal`、`equation-sea`、`endfield-baker`、`miku`、`diy-journal`）的旧式 `_<local>_` 与 `codeBlock` 选择器，同步刷新 `src/reviewed-hooks.generated.ts`。
- **工作区扩展与冷却豁免对账（`pnpm-workspace.yaml`、`package.json`）**：在主仓与四个卫星仓同步补充 `@deepseek-ai/dsh-launch-environment` 及本次新增接入的 `0.2.3-alpha.2` SDK 包（`dsh-client-remote-connection`、`dsh-client-ui-chat`、`dsh-client-ui-session-panel`、`dsh-plugin-market-index`）的 `devDependencies`、`packageExtensions` 与 `minimumReleaseAgeExclude`。

## 原生优先的重叠盘点

- **正式整包下线并移除 `packages/dsh-remote-web-ui`**：经操作者明确确认，浏览器配对、二维码/链接访问与审批能力统一交由官方 `@deepseek-ai/dsh-client-remote-connection` 承接，公网/局域网隧道中继与 iOS 协议由 `@linxin666/dsh-remote-bridge` 承接。已从主仓、README、发布清单以及覆盖率/测试基线移除 `packages/dsh-remote-web-ui`，仅在 `packages/dsh-web-all/aggregate.yml` 保留 `tombstones`/`retiredPlugins`/`shellNotes` 的静默 no-op 兼容以保护历史用户配置。
- **移除插件自建的 CSS-module DOM 注入**：在主仓与全部四个卫星仓中以官方 `DocumentStyles` 的 `meta().stylesheets` 管线取代 `shared/tsdown.client.ts` 中内联的 `<style data-plugin-css>` 注入，将样式去重、排序与卸载清理权交还官方渲染器。
- **评估 `@deepseek-ai/dsh-client-config`（`SyncedConfig`）并保留 `configForms`**：上游 `SyncedConfig` 仅提供宿主向客户端的只读顶层 `Volatile` 推送、不含写回能力；交互式设置卡仍须使用官方 `configForms` / `settings-form.ts` 契约。

## 被否决的替代方案

- 继续将 `packages/dsh-remote-web-ui` 作为独立例外与官方 `dsh-client-remote-connection` 并存：在确认官方远程连接已覆盖浏览器访问且 `dsh-remote-bridge` 承接隧道与 iOS 中继后予以否决，避免维护平行的配对与鉴权面。
- 在 `shared/tsdown.client.ts` 中继续保留手工 `<style data-plugin-css>` 注入器：因官方 `DocumentStyles` 已按 `[data-plugin][data-path]` 接管去重、排序与热卸载清理而被否决。
- 在 `plugin-market-index.json` 中为缺少显式版本的社区插件伪造 `0.0.0` 占位版本：因格式 1 索引会直接参与客户端安装与更新判断而被否决，只输出具备合法精确 SemVer 的条目。
- 在 `dsh-liangshen` 或 `dsh-diagrams` 中将 `subagentModelSelection` 或 `slots` 声明为强必需 `inject`：因精简宿主与独立测试组合可能不挂载这些可选服务而被否决，保持可选注入与优雅回退。
