# Agent Note: 规范技能中心标题显示与分组作用域描述

状态：已实现 (implemented)

## 问题背景

在 `dsh-skill-explorer`（#1215）中：
1. 技能中心弹窗顶部标题旁固定显示了扫描到的第一个项目的绝对路径（`cwd: ...`），在多项目或非该项目会话中打开时会误导用户；
2. 项目级技能分组描述写死为「仅当前项目」，但在多项目或全局查看场景下容易引起混淆。

## 技术决策

1. 在 `SkillPanel.tsx` 中移除弹窗头部副标题的 `cwd` 路径展示，保持「技能中心」主标题简洁清晰；
2. 在 `collect.ts` 与 `locales.ts` 中规范分组提示文案：
   - 项目技能：明确标明「存放于项目目录，作用于对应项目」；
   - 用户技能：明确标明「全局技能（~/.dsh/skills、~/.agents/skills），本机所有项目共享」；
   - 系统内置：明确标明「DSH 内置与插件随附的全局技能」。

## 影响与收益

- 弹窗头部不再出现误导性的单一项目物理路径；
- 技能列表分组准确传达了全局共享与项目级作用域的区别。

## 验证结论

在 `packages/dsh-skill-explorer/tests/panel.spec.tsx` 中补充了单元测试，`dsh-skill-explorer` 73 项测试全部通过。
