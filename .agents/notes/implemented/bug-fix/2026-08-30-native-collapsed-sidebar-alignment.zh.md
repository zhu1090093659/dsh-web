# Agent Note: 原生折叠侧边栏入口对齐

Status: implemented

## Problem

任务看板和 SSH 依赖全家桶的 `data-dsh-frame` 标记才能应用折叠入口样式。单独安装插件时，官方默认界面只提供 `data-sidebar-collapsed`，没有这个额外标记。入口保留展开态内边距和可见的标签盒，导致图标相对原生侧栏图标向右偏移 4 个 CSS 像素。

## Decision

两个插件的样式表均以原生 `[data-sidebar-collapsed]` 祖先匹配 CSS Modules 限定的入口和标签规则。既有图标尺寸、点击区域尺寸、移动端触控尺寸、主题 token 和展开态样式保持不变。同一选择器也匹配经过全家桶标记的界面容器。

## Alternatives considered

补加或强制依赖全家桶兼容标记会让独立插件耦合到无关 bundle，单独安装场景仍然无法正常工作。

硬编码负边距或位移只能补偿某个渲染偏差，仍会保留展开态内边距和标签布局。既有折叠布局一旦能匹配原生界面，就已经表达了预期对齐方式。

## Consequences

官方默认皮肤无需自定义皮肤或全家桶即可居中显示受影响图标。回归测试将真实入口 CSS 应用到原生和带全家桶标记的 DOM fixture，检查折叠态图标居中且标签隐藏，并验证移除折叠属性后恢复展开态文字和内边距。浏览器证据覆盖真实默认界面；无需修改 DSH 源码。
