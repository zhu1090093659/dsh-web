# Agent Note: Issue batch 1587-1600 — session reuse, packaged-CLI discovery, plugin-card seats, console decoding, and z.ai plans

Status: implemented

部分被 [family plugin cards resolve their seat from the loaded settings group](2026-09-17-family-plugin-card-seat-follows-the-loaded-group.md) 取代：其 #1589 规则以「官方 keyed 席位是否已声明」判定席位，而该席位在每个 harness web 构建上都已声明，于是每张家族卡片都去了官方「插件」页，家族分组自己的分区被留空。席位判定现改为以「设置分组是否已加载」为准。本记录中的其余五项修复不受影响。

本批次交付的 #1592 侧栏面已由 [usage 侧栏面移除](../simplification/2026-09-18-usage-sidebar-surface-removed.md) 删除：入口行、可折叠面板与 entry-core 尾部 actions API 均已移除，用量只剩设置分区一个面。仍然有效的是 #1592 的宿主侧部分——回环加已配对设备的信任围栏及其路由。

## Problem

六个 open issue 报告的缺陷与缺口，可归结为三类共同的错误——在错误的时机求值的规则、只存在于一种部署形态的席位/启动路径，以及被复制传播的字节/编码假设：

1. **#1587 —— 任务看板会话复用从不生效。** `reusableSessionId` 读取 `task.executions` 的最后一条，但启动路径在 `startExecution` 追加本次未结算记录之后才调用它，因此数组末条恒为未结算行，复用恒早退。
2. **#1588 —— 桌面安装包报 `dsh CLI not found on PATH`。** `findDshBinary` 只搜索 PATH 与 `node_modules/.bin` shim；桌面运行时把 CLI 放在 `resources/runtime/host/node_modules/@deepseek-ai/dsh/lib/bin.js`，并且刻意删除所有 `.bin` 目录（符号链接 shim 无法在安装包中存活），因此一个候选都不存在。
3. **#1589 —— 未装家族分组时远程访问设置卡缺失。** 五个家族插件把卡片注册进 `dsh-web-settings` 声明的 list 席位 `web-ui.plugin.item`；只装家族插件、未装该分组的 profile 只声明官方 keyed 席位 `settings.plugin.item`，而每个插件都吞掉了注册异常，卡片因此静默不渲染。
4. **#1600 —— 插件管理器逐 chunk 按 UTF-8 解码 CLI 输出。** `capture()` 调用 `chunk.toString()` 并按字符截断，于是 Windows OEM 代码页（CP936/GBK）变成替换字符、跨两次 `data` 读取的字符产生两个替换字符，且预算按字符计数而数据本身按字节有界。
5. **#1597 —— z.ai（GLM）编程计划探测不到。** GLM 适配器只服务 `zai-coding` / `zai-coding-cn`，而 pi-ai 目录把国际编程计划注册为 `zai`；解析器还按行位置键控窗口、把 `TIME_LIMIT`（MCP 请求上限）渲染成配额窗口，且对积分制套餐没有精确比例。
6. **#1592 —— 侧栏没有用量展示面。** 用量数据只能在设置分区内查看，且其宿主路由仅限 loopback，已配对的局域网浏览器读不到同一份 overview。

## Decision

1. `core/session-reuse.ts` 改为从执行列表末尾向前查找「最近一条**已结算**且带 session id 的执行」，其余守卫（opt-in、名册已知、会话在册且空闲）全部保持不变。
2. `findDshBinary` 额外探测运行中宿主入口脚本旁的 `lib/bin.js`（`dirname(argv[1])/../lib/bin.js`）；`dshSpawnCommand` 把解析出的 `bin.js` 交给宿主自身的解释器执行（`process.execPath`，既有的 `ELECTRON_RUN_AS_NODE` 分支覆盖 Electron 宿主），因为脚本路径在 Windows 上没有启动器。
3. 新增共享模块 `shared/client/settings/plugin-card-seat.ts` 独占席位判定：探测 `ctx.slots.spec('settings.plugin.item')`，宿主声明官方 keyed 席位时按设置命名空间注册进去，否则注册进家族 list 席位。被拒绝的注册改为记录一次 `console.warn`，不再静默吞掉。五个家族插件（remote-web-ui、task-board、doctor、tool-describe-image、liangshen）统一经它注册。
4. 新增共享模块 `shared/host/console-output.ts` 独占子进程输出采集：原始字节在字节预算内累积，仅在读取时解码一次（`decodeConsoleBytes`），优先严格 UTF-8，否则取丢失字符最少的候选（GBK，其后为宽松 UTF-8）。预算从头部裁剪，绝不落在 UTF-8 续字节上，并丢弃由接缝引入的一个前导替换字符。`dsh-plugin-manager`（gateway + routes 版本探测）与 `dsh-remote-web-ui`（`runUpdate`）都改用它。
5. GLM 适配器在 `zai-coding` / `zai-coding-cn` 之外服务 `zai`，按 provider 的 `unit` 码键控窗口（3 = 5 小时、5 = 每月、6 = 每周），`CREDIT_LIMIT` 行优先读取精确的 `currentValue` / `usage` 比例、否则回落 `percentage`，并完全跳过 `TIME_LIMIT` 与未知 unit。
6. `dsh-usage` 新增侧栏面：经共享 sidebar-entry core 注入的入口行（家族位置取 `after`，落在任务看板 / SSH / 技能中心之后、工作区浏览器之前），以及其下方读取同一份 overview 文档的面板。入口行落位面板的刷新与折叠控件；mount 拥有单一 open 状态并持久化在 `localStorage`（`dsh-usage.sidebar.collapsed`）；折叠态渲染当前提供方今日用量的一行摘要条（见[宠物解耦笔记](../simplification/2026-09-17-usage-pet-decoupling-collapsed-summary.md)），轮询节奏为展开 10 秒、折叠 30 秒、页面隐藏时暂停；宿主路由改用共享配对围栏（`shared/host/pair-access.ts`）：回环始终放行、装有 `dsh-remote-web-ui` 时已配对的设备 cookie 放行、未配对的局域网请求仍返回 403。

## Alternatives considered

- **#1587**：保留末条规则，改由调用方传入上一次的任务快照。否决：该规则是复用的唯一裁定者，必须对它拿到的任何任务记录都正确；调用方快照会在下一个调用点静默失效。
- **#1588**：在桌面载荷中放入一个 `.cmd` shim。否决：运行时构建器删除 `.bin` 目录正是因为符号链接 shim 无法在安装包中存活，重新引入只会把清晰的「未找到」换成一个在用户机器上损坏的 shim。
- **#1589**：由每个插件各自探测官方席位，或在每个插件里再声明一遍家族席位（旧设计）。否决：席位是部署属性，逐插件复制探测会让五份实现漂移；共享 helper 把判定收敛到一处。同样否决无条件同时注册两个席位——槽只能有一个声明父级，第二次注册必然抛错。
- **#1600**：只修 `gateway.ts`（issue 点名的位置）。否决：issue 明确要求同一缺陷类的每个调用点一致处理，而 `dsh-remote-web-ui` 在其 #1430 修复之后仍带着同样的逐 chunk 解码缺陷。
- **#1600**：解码后按字符窗口做预算。否决：那会先解码整条（无界的）流，正是 issue 指出的平方级开销。
- **#1597**：把 `TIME_LIMIT` 也当作窗口接受。否决：它是每分钟 MCP 请求上限而非套餐配额，渲染它等于展示一个不存在的配额。
- **#1592**：通过 slot 渲染面板而非 DOM 注入。否决：官方侧栏没有声明任何外部插件可用的 list 席位（语义属性契约的「已知脆弱点」之一）；家族既有做法是 DOM 注入 + 共享自愈 core。
- **#1592**：保持用量路由 loopback-only，另发一条配对专用路由。否决：复制围栏正是围栏漂移的成因；家族已有唯一的共享配对判定。

## Consequences

- 开启复用的任务现在确实复用，这正是文档一直描述的行为；若上一次会话已消失、正在运行或名册未知，仍会新开会话。
- 桌面安装包能解析自带的 CLI，无需 PATH 即可安装/更新；存在 PATH 项时仍以 PATH 优先。
- 家族插件卡在装有或未装 `dsh-web-settings` 的部署上都能渲染，被拒绝的席位现在可从浏览器控制台诊断，而不再不可见。
- CLI 子进程输出只解码一次，GBK 报错文本与跨块的多字节字符都能正确渲染；保留的 tail 以字节为界，对 CJK 输出来说等于收窄了有效字符窗口。
- 个人套餐页签覆盖目录实际发布的 z.ai 路由，窗口按 unit 键控、积分制用精确比例；未知 unit 与 MCP 上限都不产生窗口，无任何可渲染内容的套餐按「无套餐数据」处理。
- 侧栏用量面板可在已配对的局域网浏览器上读取宿主数据；设置分区与侧栏共用同一份 overview 文档与同一条围栏。
- 未移动任何 host/client 边界：新增共享模块分别位于 host 侧（`console-output`）与 client 侧（`plugin-card-seat`），并按 sync 清单携带生成的副本。sidebar-entry core 在本批次中未改动；后续改动为其新增了可选的尾部 actions API（见上文控件记录），不带 actions 的行逐字节不变。
