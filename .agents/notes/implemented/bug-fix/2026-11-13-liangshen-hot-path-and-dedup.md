# Agent Note: LiangShen hot-path consolidation, helper deduplication, and YAML prototype safety

Status: implemented

This note owns the per-step hot-path execution structure, shared durable-log helpers, host preset-override caching, YAML map prototype safety, and composer lever hot-path guards in `packages/dsh-liangshen`, refining the runtime mechanics of [LiangShen shell and paging make PTC the executed surface](../feature/2026-09-17-liangshen-shell-and-paging-ptc-surface.md), [LiangShen delivers workspace instructions in the user role](../feature/2026-09-17-liangshen-workspace-instructions-user-role.md), and [The LiangShen lever in the new-session composer](../feature/2026-09-11-liangshen-composer-lever.md) while keeping their user- and model-facing contracts intact.

## Problem

Long-running LiangShen sessions invoke `tools/post-execute`, `tools/result`, `system-prompt/assemble`, and `agent/pre-step` on every step or tool call against a growing durable event stream. Partitioning the tool surface three times per paging sync, resyncing scope restrictions after every resident read-only tool call, scanning the event log in separate passes for `plan/mode`, `todo/write`, `fact_register`, `tool/result`, and `tool_activate`, allocating a `Set` per step to locate the latest visible plugin message, maintaining duplicate log-walking helpers across four preset modules, and tracking `touchedDirs` with `snapshotEvents()` replay even when `instructionSource` is `'host'` compound linear per-step CPU and allocation work as session length grows.

On the host and browser surfaces, reparsing the base `PresetDefinition` on repeated `rearm()` / `declare()` calls within an activation (such as `loader/volatile-update` settings writes), writing parsed YAML map entries via bracket assignment where a `'__proto__'` key mutates the target object's prototype instead of defining an own enumerable property, running `detectPreset()` DOM/storage reads and `restoreLabel` computation on non-blank sessions (`!facts.blank`), and recreating the `face()` instance and `locale.bind('liangshen')` translator across a controller's lifetime (primarily on blank sessions rendering the lever and calling `face.t(...)`) add redundant work and expose a prototype-pollution hazard in `parseMap`.

## Decision

1. **Single-partition paging and selective post-execute resync (`presets/liangshen/tool-catalog.mjs`, `presets/liangshen/paging.mjs`).** `syncScopePaging` partitions `fullSurface` once via `partitionWireTools(fullSurface, pagedToolPatterns, [])` instead of three separate partition passes; `tools/post-execute` skips `syncBeforeAssembly` when the scope is already paged and the executed tool is a resident non-activating tool (neither `tool_activate`, `run_code`, nor matching `pagedToolPatterns`); `system-prompt/assemble` measures resident surface tokens and the top-3 heaviest tools in a single pass; and rendered catalog text is memoized per assembly state.
2. **Single-pass working-context fold and shared durable-log helpers (`presets/liangshen/working-context.mjs`, `presets/liangshen/fact-ledger.mjs`, `presets/liangshen/paging.mjs`, `presets/liangshen/tool-activate.mjs`, `presets/liangshen/subagent-routes.mjs`).** `renderWorkingContext` folds `plan/mode`, `todo/write`, the fact ledger (via shared `applyFactLedgerEvent`), errored `tool/result` `callId` entries, and `tool_activate` presence in one pass, skipping activation replay when no `tool_activate` events exist; shared `sessionEvents` (preserving [session events SDK compatibility](2026-09-03-liangshen-session-events-sdk-compat.md) while wrapping `snapshotEvents` in `try/catch`), `textOf`, `latestVisiblePluginMessage` (using `nodes.lastIndexOf` without per-step `Set` allocation), and `reconcileStepMessage` live in `presets/liangshen/paging.mjs` and replace duplicates across `tool-catalog`, `working-context`, `tool-activate`, and `subagent-routes`.
3. **Gated instruction tracking in `minimal-prompt` (`presets/liangshen/minimal-prompt.mjs`).** `tools/result` and `getSessionState` skip `touchedDirs` tracking and `snapshotEvents()` replay unless `instructionSource === 'system-prompt'`, keeping the listeners registered for contract compatibility while covering both `tool/call` and `tool/ptc-dispatch` during `'system-prompt'` replay.
4. **Host per-activation declaration cache, YAML prototype safety, and browser lever hot-path trim (`src/index.ts`, `src/composition.ts`, `src/client/lever-controller.ts`).** Within each `applyImpl` activation, `basePreset` lazily caches the parsed base `PresetDefinition` across repeated `rearm()` / `declare()` calls without mutating it; `parseMap` defines keys with `Object.defineProperty` so `'__proto__'` remains an own enumerable property; and `LeverController` gates `detectPreset()` DOM/storage lookups and `restoreLabel` computation on `facts.blank` (skipping them on non-blank sessions), while caching the `face()` instance and lazily caching the resolved `locale.bind('liangshen')` translator across the controller's lifetime.

## Alternatives considered

- **Caching incremental activation and working-context state in memory across steps instead of folding `snapshotEvents()`.** Rejected: session compaction, fork, and resume rewrite or replace the durable event stream underneath process memory; single-pass folds and selective hook skips capture the speedup while preserving replay determinism.
- **Skipping `syncBeforeAssembly` after `run_code` calls in addition to native resident calls.** Rejected: under `ptc`, a `run_code` program can call `tool_activate` or active paged tools internally via `tool/ptc-dispatch`, mutating the active set or LRU order before the next prompt assembly.
- **Omitting `minimal-prompt` hook registration altogether when `instructionSource !== 'system-prompt'`.** Rejected: keeping the listeners registered preserves uniform hook topology and contract expectations across modes while reducing inactive-mode cost to a constant-time guard.
- **Constructing `Object.create(null)` maps in `parseMap` instead of plain objects with `Object.defineProperty`.** Rejected: callers and structural equality checks expect standard `Object.prototype` behavior on parsed YAML maps, whereas `Object.defineProperty` keeps ordinary object prototypes while neutralizing `'__proto__'` setter side effects.

## Consequences

Paging restrictions, catalog rendering, working-context reconciliation, `system-prompt` touched-directory discovery (across both `tool/call` and `tool/ptc-dispatch`), host preset overrides, and composer lever behavior preserve their observable contracts. Durable-log helpers have a single implementation in `presets/liangshen/paging.mjs`, the per-activation cached base preset definition remains immutable across repeated `rearm()` / `declare()` re-declarations within an activation, and `parseMap` handles `'__proto__'` keys as ordinary own data properties.

In the 5-run median 100-step benchmark on Node v24.21.0 (`linux x64`), full-pipeline time at 1,500 events is 21.54 ms versus the 38.22 ms baseline (-43.6%). In the 3,000-event per-hook breakdown, `tools/post-execute` (`read`) is 0.09 ms (from 14.04 ms), cold `tools/result` (`host` mode) is 0.00 ms (from 1.37 ms), `system-prompt/assemble` is 17.87 ms (from 19.44 ms), and `agent/pre-step` is 14.71 ms (from 28.05 ms).
