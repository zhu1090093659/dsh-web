# Agent Note: dsh-ssh lifecycle, resource safety, and hot-path hardening

Status: implemented

## Problem

An end-to-end audit of `packages/dsh-ssh` identified seven groups of runtime lifecycle, data-integrity, and resource-leak defects across the host plugin entry, connection pool, terminal sessions, SFTP transfers, JSON store, HTTP routes/tools/tunnels, and React panel client:

1. **Host re-sync killed live terminals**: `src/index.ts` re-registered all routes, tools, and the `dshSsh` service inside `ctx.config.onChange`, disposing `terminalSessions` and dropping open WebSocket PTYs whenever unrelated volatile settings (such as `terminalFontFamily` or `connectTimeoutMs`) changed.
2. **Pool handshake hangs, in-flight races, and split UTF-8 output**: `connectClient` omitted `'close'` pre-ready (hanging forever when a peer closed right after banner exchange because `ssh2` clears `readyTimeout`), `doAcquire` could repopulate `engine.pool` after `dropAlias`/`dispose` or fail to close jump `hops` when the target closed, `withClient` ignored `AbortSignal` while waiting in `acquireQueue`, and `execCommand` decoded `Buffer` chunks independently while pruning output in code units instead of UTF-8 bytes.
3. **Terminal backpressure stalls and O(N^2) scrollback eviction**: `TerminalSessionRegistry` called `applyBackpressure()` when `ws.bufferedAmount > HIGH_WATER` with no `drain` resume hook on WebSocket, called `String` `.toString('utf8')` per chunk across multi-byte boundaries, used `Array.prototype.shift()` for ring eviction, and accepted non-finite terminal dimensions or non-string frames.
4. **SFTP nested upload failures and wrong speed window**: `mkdirRemote` normalized paths with host `dirname` (breaking Windows host uploads to POSIX remotes) and created only the leaf directory, missing nested subdirectories during recursive uploads; `fastTransfer` computed `speedBps` by dividing window bytes over total elapsed duration instead of window duration.
5. **Host store cache mutation, N-write ssh-config import, and HTTP route leaks**: `HostStore` mutated cached entries in place before validation completed (corrupting memory cache on rejected `update`/`updateKey`), ran full read/serialize/atomic-write cycles per imported host in `importFromSshConfig`, reused fixed `.tmp` filenames, checked raw `body` instead of `resolved` in `PATCH /api/dsh-ssh/hosts` (missing `managedKeyId`-only credential swaps), sanitized only quotes in download `Content-Disposition`, and leaked open `ReadStream` fds and 0600 staged files on aborted downloads.
6. **Cluster error drops and tunnel/proxy-command lifecycle gaps**: `cluster` dropped `result.error` on timeout/cancelled runs and duplicated inconsistent selector validation across three files; `sshTunnelTool` returned `ok: true` when `startTunnel` returned `state: 'failed'`; `tunnel.ts` could pipe onto an already-destroyed socket, lacked `inFlight` protection during `server.listen` or post-listen `error` cleanup, and killed active `exec`/`sftp` records in `stopTunnel` when `inFlight > 0`; `proxy-command.ts` left 2s `SIGKILL` timers active after clean exit and stacked `stdin` error exit listeners.
7. **Client form clearing, duplicate host loads, duplicated scrollback replay, and silent tunnel/transfer failures**: `HostFormDialog` converted cleared `description`/`environment`/`location` fields to `undefined` (no-op under PATCH); `HostsTab` fired two `listHosts` calls on mount, used a scalar `testingAlias` during parallel group tests, and dropped active search queries on reload; `TerminalTab` skipped clearing `retainedScreens` after panel unmount/remount (`renderedRef.current === undefined`), doubling host-replayed scrollback; `PanelController.appendTerminalOutput` used `shift()` and left single chunks > 256 KiB unbounded; `SshApi` could fire `onExit` twice, dropped unterminated NDJSON tails/flushes on upload, and left `FileSystemWritableFileStream` un-aborted on failed streamed downloads; `TunnelsTab` treated `state: 'failed'` starts as success and lacked unmount guards on async handlers.

## Decision

Keep every external protocol, tool schema, config contract, and generated shared copy (`scripts/sync-shared.mjs`) intact while fixing each boundary cleanly:

- **Idempotent config sync**: Track registered surface flags (`enabled`, `announceToAgent`) in `src/index.ts` so `sync()` tears down and rebuilds routes/tools/service or the settings section only on transitions of those structural flags.
- **Private `WeakMap` pool lifecycle & `StringDecoder` streams**: Store per-engine `PoolLifecycle` epochs/generation tokens in a module-private `WeakMap<PoolEngine, PoolLifecycle>` inside `src/engine/connection-pool.ts` so aborted or post-dispose `doAcquire` completions never reinsert stale connections, without widening the public `PoolEngine` interface. Decode PTY and `execCommand` streams with per-stream `StringDecoder('utf8')`.
- **Event-driven WebSocket backpressure & parallel-array O(1) rings**: Wire WebSocket flush resumption via `ws.send(payload, session.onDrain)` in `terminal-sessions.ts`, and replace wrapper-object / `shift()` queues with parallel flat arrays plus head pointers (`buffer`/`bufferChunkBytes` on host; `chunks`/`chunkBytes` in `PanelController`) and UTF-8 boundary tail trimming for oversized chunks.
- **Posix SFTP directory cache & windowed speed**: Route SFTP directory logic through `posix` helpers, probe deep targets in one `stat` fast path before bottom-up/top-down `mkdir`, memoize ensured prefixes per recursive upload in a `Set<string>`, and track per-window timestamps (`prevEmit`) for `fastTransfer`.
- **Immutable store writes & batched import**: Refactor `HostStore` mutators to validate all fields first, build new immutable entries/`StoreFile` snapshots (strictly omitting `keys` when pre-feature stores lack it), compute `listKeys` `usedBy` via one O(H) `Map` pass, batch `importFromSshConfig` into a single `save()` with unique per-PID temp filenames, check `resolved` patches for `dropAlias`, sanitize `Content-Disposition` via character code filtering (keeping `oxlint` free of control-regex literals), and tear down `createReadStream` before `unlink` on aborted downloads.
- **Shared cluster selector & guarded tunnel/proxy lifecycles**: Export `hasClusterSelector` from `src/engine/cluster.ts` for routes and tools, preserve `result.error` conditionally on `ClusterResult`, honor `tunnel.state !== 'failed'` across `ssh_tunnel` and `TunnelsTab`, guard `tunnel.ts` `forwardOut`/listen/stop paths with `socket.destroyed` + `record.inFlight`, and deduplicate `proxy-command.ts` timers/listeners.
- **Single-pass client state transitions**: Clear `retainedScreens` unconditionally before attaching in `TerminalTab`, preserve search and parallel per-alias test state in `HostsTab`, submit `''` on cleared optional PATCH strings in `HostFormDialog`, deduplicate `SshApi` socket `onExit`, and abort/cancel incomplete transfer streams in `finally`.

## Alternatives considered

- **Add lifecycle fields (`generation`, `disposed`) directly onto `PoolEngine`**: Rejected because external tests construct `PoolEngine` structural literals directly; keeping lifecycle tokens in a module-private `WeakMap` preserves 100% source compatibility.
- **Use POSIX `realpath`/symlink helpers or rewrite `SshEngine` around a custom state actor**: Rejected to keep diffs minimal, reviewable per subsystem, and compatible with shared workspace contracts.
- **Keep `ws` unpaused or estimate UTF-8 bytes by `str.length * 3`**: Rejected because unpaused streams exhaust memory on fast remote output and multiplying length by 3 breaks exact 256 KiB scrollback budgets across ASCII vs CJK mixes.

## Consequences

- **Bench A (`HostStore.importFromSshConfig`, 200 Host blocks, fresh store)**: Baseline median 31.21 ms (`[31.47, 30.93, 30.51, 31.21, 32.45]` ms) improved to median 0.80 ms (`[0.75, 0.80, 0.93, 1.03, 0.56]` ms) by writing once instead of 200 times.
- **Bench B1 (`TerminalSessionRegistry`, 10,000 x 256 B UTF-8 chunks)**: Baseline median 8.89 ms (`[10.07, 8.89, 7.92, 9.75, 7.01]` ms) shifted to median 13.84 ms (`[14.40, 13.42, 13.35, 13.84, 13.95]` ms), adding ~4.95 ms (0.49 us/chunk) for `StringDecoder` and exact `Buffer.byteLength` accounting in exchange for multi-byte safety and O(1) eviction (70,000 x 4 B chunks finishes in 24.4 ms).
- **Bench B2 (`PanelController.appendTerminalOutput`, 10,000 x 256 B UTF-8 chunks)**: Baseline median 9.14 ms (`[9.38, 9.14, 7.60, 8.24, 9.70]` ms) improved to median 1.51 ms (`[1.94, 1.82, 1.39, 1.51, 1.40]` ms) by replacing iterator-based byte counting and `Array.prototype.shift()` with indexed UTF-16 `charCodeAt` scanning and head-pointer ring compaction.
- **No external schema or surface drift**: `sync-shared.mjs` generated files, locale dictionaries, CSS layout, and exported `dshSsh` service interfaces remain unchanged.
