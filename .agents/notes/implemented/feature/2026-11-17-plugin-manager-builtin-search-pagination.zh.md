# Agent Note: 内置插件搜索与有界分页

Status: implemented

## Problem

内置插件分组可以从少量全局 Loader 行展开为部署中的全部行。一次性渲染完整集合会让官方插件页出现数百行内容，用户只能在无关的包行之间滚动寻找目标模块或条目。

## Decision

`packages/dsh-plugin-manager/src/client/BuiltinPlugins.tsx` 中的分组在已读取的行集合上执行本地过滤。去除首尾空白并转为小写的查询在当前所选范围内匹配本地化标题、模块包名、行 id 与组合包归属。标题计数反映过滤结果，没有匹配行时显示独立空状态，Escape 清空查询。

过滤结果每页最多渲染 20 行，并提供上一页、下一页与页码/结果摘要。搜索、清空查询或切换范围都会回到第一页。当前页会收敛到实际结果页数，重复标签检测覆盖整个过滤结果而不是只覆盖当前页。搜索、范围切换与分页不会重读 Loader、调用管理器或改变启停状态；官方写入及写入后的重读路径保持不变。

控件沿用包内现有主题令牌样式，在窄屏下换行，并提供简体中文、英文与俄文文案。包 README 记录同一套本地视图行为。

## Testing

内置插件组件套件共有 37 个测试。搜索与分页用例驱动真实组件，覆盖本地化标题、模块、行 id 与归属匹配，空结果与 Escape 恢复，20 行上限与第二页，视图变化不发生 Loader 读取或管理器写入，以及搜索、清空和范围变化后的第一页复位。聚焦套件通过。

## Alternatives considered

- **用“加载更多”追加下一页：** 否决，因为反复点击后 DOM 与页面仍会无限增长，而主要问题正是管理页本身的长度。
- **把完整列表放进固定高度的内部滚动容器：** 否决，因为这会引入嵌套滚动并打断官方页面的自然文档流。分页同时约束渲染行数与外层页面长度。
- **增加 host 侧搜索与分页：** 否决，因为两种范围本来就来自同一份完整快照。host 查询接口只会增加契约与网络工作，不会改变权威数据或写入行为。

## Consequences

读者可以搜索并翻页浏览展开后的清单，同时最多只渲染 20 个内置插件行。搜索保留范围语义：读者展开列表后，组合包归属行才参与匹配。查询与页码是组件本地状态，卸载后不持久化。Agent 预设的组合与渲染不在本次改动范围内。
