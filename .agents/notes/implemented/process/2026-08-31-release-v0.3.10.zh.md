# Agent Note: Release v0.3.10

Status: implemented

## Problem

家族需要发布下一个统一版本，包含 v0.3.9 tag（2026-08-30）之后合入 `dev` 的全部内容：dsh-better-sidebar 以 0.18.0-alpha.0 回归、新增 `@linxin666/dsh-i18n` 俄语语言包、跨包的 i18n locale 字典迁移、dsh-archived-chats 社区插件注册、e2e token URL 修复与仓库加固提交。发布门禁要求在版本 bump / tag / npm 发布之前对 `v0.3.9..dev` 全范围做自动升级兼容性审计。

## Decision

按标准全仓统一版本流程在隔离 worktree 发布 v0.3.10（0.3.9 的下一个补丁版本），共享 checkout 保持不动以兼容并行会话。审计将该范围判定为可安全自动升级：

- 既有包没有任何包身份、契约、持久化或线协议标识符变化：八个 i18n 迁移包只是把 UI 文案搬进各自 locale 字典（settings section id、API 路径、存储 key 全部冻结）。
- 聚合包改动全是增量：两个新增 insert 行（新 bundle 的 `web-ui-i18n`、外部插件按 alpha.2 兼容版本回归的 `web-ui-better-sidebar`）加一个新依赖。旧 profile 上没有任何针对这两行的冻结禁用状态——2026-08-30 的排除是「整行省略」而非 `disabled:` 覆盖。
- `@linxin666/dsh-i18n` 作为纯浏览器插件加入家族（type-only `@deepseek-ai/*` 导入、无 settings section、`inject = ['locale']`），声明 `engines.dsh >= 0.1.2-alpha.1`，等于或低于所有兄弟包下限，也低于发布验证钉点 `@deepseek-ai/dsh@0.1.2-alpha.2`。
- legacy 聚合包双发窗口保持关闭：`LEGACY_DUAL_PUBLISH_WINDOW_OPEN = false` 且 `@linxin666/dsh-web-ui-all` 已 deprecate，管线步骤对 0.3.10 是 no-op。

验证证据：全新安装挂载冒烟（真实 alpha.2 宿主、keyless `dsh web`、Playwright：帧 + better-sidebar 挂载、archive-manager 缺席、无崩溃条）与 0.3.9→0.3.10 升级路径模拟（scratch profile 上真实 0.3.9 registry 安装，`dsh plugin add file:<0.3.10 tarball>` 并把全部家族改写为本地 tarball，`--dump-config` 预检，行/依赖/版本断言，数据文件标记存活，升级后同一 Playwright lane 启动通过）。

## Alternatives considered

- 只跑 CI 门禁、不做升级路径模拟：拒绝——硬门禁明确禁止在范围新增 bundle 行与依赖时只做全新安装验证；模拟成本低且证明了真实更新流。
- 发布 legacy `@linxin666/dsh-web-ui-all@0.3.10`：拒绝——过渡窗口已硬关闭，已 deprecate 的包必须停在窗口末版本。

## Consequences

- npm `@linxin666/*` 全家族发布到 0.3.10（`latest`）；`@linxin666/dsh-i18n` 以 0.3.10 首次发布。
- 聚合包下次安装即获得 better-sidebar 右侧面板与 ru 语言包；均为增量、无需迁移，plugin-manager 更新与 Doctor 预检不受影响。
- Release notes 为已提交的双语 `docs/release-notes/v0.3.10.md`（中文默认视图 + English 折叠）；`dsh-web-ui-all` 保持 deprecate 于 0.3.6。

后续（2026-08-31）：CI verify-release 挂载冒烟连续两次失败，报 `ERR_PNPM_FETCH_404` 解析 `@linxin666/dsh-i18n@0.3.10`——该包首次发布：e2e-mount-rewrite 探测见到 packument（200），紧随其后的安装却命中过期的边缘缓存（404）。registry 侧一致性几分钟内自愈；补救是 `gh run rerun --failed`（不改 tag、不碰 publish 任务）。下一个发布若引入全新家族包，应加固 `scripts/e2e-mount-rewrite` 或给冒烟安装加重试，而不是赌重跑运气。
