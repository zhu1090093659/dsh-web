## Alternatives considered

Letting authors rebase their own conflicting branches was rejected for this pass: the conflicts are purely mechanical generated-artifact ordering, the maintainer can resolve them deterministically by regeneration, and author round-trips would leave the queue blocked for days. Hand-editing the four manifest JSON files instead of regenerating was rejected: `market-build --check` derives the manifests, so manual resolution risks a committed tree no build can reproduce. Squash merges were not used: this repository's convention for external contributions is merge commits titled `merge PR #NNNN`. Blocking #1449 on the description contradiction and order tie was rejected: dev already tolerates a duplicate order value and both issues are cosmetic; they are recorded for the author instead. Merging #1420 or #1449 while their branch CI still ran was rejected; each merge waited for a CLEAN state.
