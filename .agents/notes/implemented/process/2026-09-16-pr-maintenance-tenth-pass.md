Merging #1582 with `--admin` while CI was red was rejected: the failure was a true finding (CRLF sources breaking the dist contract), not a stuck gate, and pushing the normalization plus rebuild to the PR branch achieved a fully-honest green — the same reasoning as the ninth pass's admin-bypass rejection, extended from stuck runs to failing ones.

Rebuilding #1582's dist before merging dev into the staging branch was attempted and corrected: the first rebuild baked the pre-#1583 74-plugin manifest, which would have conflicted with dev's 75-plugin state at merge time. Merging dev into the staging branch first makes the PR merge conflict-free and is now part of the pattern.

Bouncing #1467 back to its author for a second rebase was rejected, consistent with the [seventh pass](2026-09-13-pr-maintenance-seventh-pass.md) rule: the staleness came from dev advancing (#1583 merged after this branch was rebuilt), the union of two independent tail entries provably preserves both intents, and the deterministic regeneration defines the artifact side.

Requiring #1582's author to re-shoot captures over the visible workspace names was rejected: the names are neutral strings, the session titles disclose nothing sensitive, and another capture round-trip would delay a fixable PR for no protective gain.
