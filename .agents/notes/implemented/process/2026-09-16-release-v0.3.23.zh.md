# Agent Note: v0.3.23 release run

Status: implemented

## Problem

v0.3.22 的记录固化了补丁发版协议：根别名钉版与 lockfile specifier 随 tag 一起移动，内嵌版本号的 bundle 在同一次提交里重新生成，自动升级兼容性审计是硬门禁。v0.3.23 包含了跨多个包、皮肤与工坊站点的多项功能与维护更新（68 个提交、261 个改动文件），因此本记录写下审计核验了哪些面、本次更新包含了什么内容、以及这次 bump 实际移动了哪些产物。

## Decision

- 目标版本由用户明确指定为 0.3.23（上一正式版本为 0.3.22，已验证发布在 npm）；`node scripts/verify-version.mjs 0.3.23` 报告 21 个家族包与根聚合包钉版全部与 v0.3.23 一致。
- v0.3.22..dev 的兼容性审计未发现持久化标识符、profile 格式、线协议或迁移面的破坏性改动。经核验保持不变的有：`packages/dsh-web-all/cordis.patch.yml`（全部行 id 与 self 行）、聚合包成员（两个版本都保持 20 行 / 19 个依赖 / 17 个客户端子包）、聚合包 `exports` 映射与浏览器 loader id、每个包的 `name`、每个 `dsh.engines.dsh` 下限（保持 `>=0.1.5-rc.1`）、`shared/host/legacy-migration.ts`、`scripts/publish-legacy-aggregate.mjs` 以及 Doctor 的迁移代码。
- 本次改动均为增量且向后兼容：`dsh-usage` 增加官方 API 用量鲸元代币券铸造；`dsh-task-board` 增加模型智能文本解析与项目分区；`dsh-pet` 气泡文字排版尺寸随宠物尺寸等比缩放；`dsh-remote-web-ui` 在隧道重连后保持公开宿主地址；`dsh-market` 采用深海画廊首页布局并具备遥测窗口新鲜度兜底；新增三套纯 CSS 皮肤（`hive-maw`、`ember-fall`、`astral-choir`）且不含可执行 hooks。
- 纯版本 bump 只移动三个提交入库的 bundle（`dsh-market`、`dsh-web-all` 与 `skins/skin-center` 的 `lib/client.js`），并保持 `scripts/lib-artifact-fingerprints.json` 一致：`pnpm libs:write` 与 `pnpm libs:check` 在 bump 后的树上通过。发布提交携带 21 个 manifest、根钉版、lockfile specifier、这三个 bundle、`docs/release-notes/v0.3.23.md` 以及本决策记录；它在 `main` 上提交，tag 从 main 打出，随后合并回 `dev`。
- legacy 双发窗口保持硬关闭（`LEGACY_DUAL_PUBLISH_WINDOW_OPEN = false`）：`@linxin666/dsh-web-ui-all` 停在 0.3.6 并带弃用说明，管线里的 legacy 步骤是 no-op。
- 桌面打包在 tag 构建时从 registry 解析预装 profile 种子，因此提交入库的种子不做提升。

## Alternatives considered

- 只 bump `packages/**` 下的 package.json：否决——根别名钉版与 lockfile specifier 会停留在 0.3.22，`verify-version.mjs` 会在发布前中止管线。
- 不校验 hash manifest 直接重建市场产物：否决——`pnpm market:build` 与 `pnpm market:check` 严格校验生成的 bundle、目录与预览图与提交产物完全一致。
- 延迟到发布后补充 release notes：否决——发布管线优先采用提交入库的 `docs/release-notes/vX.Y.Z.md` 双语说明，早准备可避免脚本草稿兜底。

## Consequences

- 从 v0.3.22 升级不需要手动迁移：两条自动路径（插件管理器更新与 Doctor 启动前迁移）落在同一套包上且无 schema 冲突。
- 三套新皮肤可直接从工坊下载安装，无需修改客户端代码。
- 发布产物与现有 DSH 宿主运行时保持完全向后兼容。

## Testing

- tag 之前对 bump 后的树执行的本地门禁：`pnpm sync-shared:check`、`pnpm typecheck`、`pnpm test`、`pnpm test:scripts`、`pnpm aggregate:check`、`pnpm runtime-deps:check`、`pnpm market:check`、`pnpm skin-center:check`、`pnpm skin-hooks:check`、`pnpm docs:check`、`pnpm i18n:check` 与 `pnpm libs:check` 全部通过。
- 版本校验：`node scripts/verify-version.mjs 0.3.23` 确认全仓 21 个包与根依赖钉版均与 `0.3.23` 一致。
- 发布后验证：tag 管线执行情况、各包在 registry 的解析验证，以及无裸 mention 的 GitHub Release 展示。
