# Agent Note: v0.3.24 发布历程

Status: implemented

## Problem

[v0.3.23 的发布记录](2026-09-16-release-v0.3.23.md)固化了补丁发版协议：根别名钉版与 lockfile specifier 随 tag 一起移动，内嵌版本号的 bundle 在同一次提交里重新生成，自动升级兼容性审计是硬门禁。v0.3.24 汇总了跨包、皮肤、工坊站点、桌面打包与 CI 的 82 个提交、444 个改动文件，因此本记录写下审计核验了哪些面、本次更新包含了什么内容、以及这次 bump 实际移动了哪些产物。

## Decision

- 目标版本由用户明确指定为 0.3.24（上一正式版本为 0.3.23，已验证发布在 npm）；`node scripts/verify-version.mjs 0.3.24` 报告 21 个家族包与根聚合包钉版全部与 v0.3.24 一致。
- v0.3.23..dev 的兼容性审计未发现持久化标识符、profile 格式、线协议或迁移面的破坏性改动。经核验保持不变的有：每个包的 `name`、`exports` 映射、`dsh.bundle` / `dsh.client` 键集合与浏览器 loader id；每个 `dsh.engines.dsh` 下限（`>=0.1.5-rc.1`，发布通道安装的钉版 `@deepseek-ai/dsh@0.1.5-rc.1` 满足该下限）；`packages/dsh-web-all/cordis.patch.yml` 与 `packages/dsh-web-all/aggregate.yml`（两者与 v0.3.23 逐字节相同，故聚合成员、全部行 id 与 self 行均未变化）；全部六个 `settings.section` 注册及其 id；全部 slot 注册名；`/api/dsh-usage/overview` 与 `/api/dsh-usage/refresh` 两个 API 路径；`shared/host/legacy-migration.ts`；`scripts/publish-legacy-aggregate.mjs`；以及 Doctor 与插件管理器的迁移代码。
- 本次全部改动都归类为带确定性的向后兼容（无需迁移）：
  - `dsh-usage` 从其设置 `Config` 中移除可选的 `bubbleMode` 键，并取消桌面宠物气泡播报。这是删除字段而非重命名：用户 profile 设置文档里遗留的旧键会被 schemastery object 接受（已用目标 schema 对遗留文档实测），因此没有读取方失败，也不需要迁移。同一包只在枚举时把休眠的目录别名归并到其在线路由，改变的是渲染出的行，而非任何已存储的标识符。
  - `dsh-task-board` 新增 `dsh-task-board.parse-model` 这个 localStorage 键并记住解析模型；没有任何既有键被重命名或删除。宿主账本保持磁盘锁格式不变，并新增 `Win32_Process` 的 CIM 兜底探测，使被受保护进程（System、svchost）复用 PID 的锁仍能被判定为过期。
  - `dsh-liangshen` 重构其内置预设树（程序化工具呈现默认 `ptc`、工具族分页与 `tool_activate`、插件设置卡片、可选的按阶段推理预算）。启动同步会替换预设目录、清理仅存在于目标端的文件，并只删除 retire 列表中点名的预设 id，同时保留运维方的 `agent.cordis.yml` 覆盖。
  - 其余均为增量：四套纯资产皮肤（`whale-maid`、`pixel-anime`、`island-life`、`remiel-starlit`）、社区索引新增 PerryLink 的七个插件与 `dsh-ppt-studio`、`dsh-workbench`、工坊「编辑推荐」分类、CI 测试纪律门禁与覆盖率棘轮，以及桌面端顺序构建 macOS 各架构。
- 纯版本 bump 移动提交入库的 bundle（`dsh-market`、`dsh-web-all` 与 `skins/skin-center` 的 `lib/client.js`），并保持 `scripts/lib-artifact-fingerprints.json` 一致：`pnpm build`、`pnpm libs:write` 与 `pnpm libs:check` 在 bump 后的树上通过。发布提交携带 21 个 manifest、根钉版、lockfile specifier、刷新后的 bundle 与指纹、`docs/release-notes/v0.3.24.md` 以及本决策记录；它在 `main` 上提交，tag 从 main 打出，随后合并回 `dev`。
- legacy 双发窗口保持硬关闭（`LEGACY_DUAL_PUBLISH_WINDOW_OPEN = false`）：`@linxin666/dsh-web-ui-all` 停在 0.3.6 并带弃用说明，管线里的 legacy 步骤是 no-op。
- 桌面打包在 tag 构建时从 registry 解析预装 profile 种子，因此提交入库的种子不做提升。

## Alternatives considered

- 只 bump `packages/**` 下的 package.json：否决——根别名钉版与 lockfile specifier 会停留在 0.3.23，`verify-version.mjs` 会在发布前中止管线。
- 为被删除的 `bubbleMode` 设置键补迁移：否决——它只是带安全默认值的 UI 偏好，且目标 schema 接受遗留键，补迁移只会增加失败面而不改变任何可观测行为。
- 把已回滚的命名空间解析修复写进发布说明：否决——该回滚精确还原了发布前行为（对 v0.3.23 的 `allowlist.ts` 净 diff 为空），把它当作已交付修复会误报产物。该项已从说明中省略，并相应调整修复计数。
- 延迟到发布后补充 release notes：否决——发布管线优先采用提交入库的 `docs/release-notes/vX.Y.Z.md` 双语说明，早准备可避免脚本草稿兜底。

## Consequences

- 从 v0.3.23 升级不需要手动迁移：两条自动路径（插件管理器更新与 Doctor 启动前迁移）落在同一套包上且无 schema 冲突。
- 仍带 `bubbleMode` 的 profile 继续正常加载，该设置只是不再产生效果。
- 四套新皮肤可直接从工坊下载安装，无需修改客户端代码。
- 已在使用梁神预设的会话在重启后采用重构后的呈现默认值；`native` 与 `both` 仍可在其插件设置卡片中选择。

## Testing

- tag 之前对 bump 后的树执行的本地门禁：`pnpm build`、`pnpm libs:write`、`pnpm libs:check`、`pnpm market:build`、`pnpm market:check`、`pnpm sync-shared:check`、`pnpm typecheck`、`pnpm test`、`pnpm test:scripts`、`pnpm test:standards`、`pnpm aggregate:check`、`pnpm runtime-deps:check`、`pnpm skin-center:check`、`pnpm i18n:check`、`pnpm emoji:check` 与 `pnpm docs:check`。
- 版本校验：`node scripts/verify-version.mjs 0.3.24` 确认全仓 21 个包与根依赖钉版均与 `0.3.24` 一致。
- 升级路径证据：共享 legacy-migration、Doctor migrate 与插件管理器 update 三套用例在 `pnpm test` 中执行；全新安装挂载冒烟（`scripts/e2e-mount.sh`）用钉版官方 CLI 把本 tag 的聚合包 tarball 装入临时 DSH_HOME 并做无头渲染，发布管线以它作为 GitHub Release 的前置门禁。
- 发布后验证：tag 管线执行情况、各包在 registry 的解析验证，以及无裸 mention 的 Release 展示。
