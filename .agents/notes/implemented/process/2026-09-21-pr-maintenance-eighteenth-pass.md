- #1607 (the Porco Rosso, Last Exile and White Snake skins, by binlecode) change requested again. The author did remove the six commercial MP3 files and the player code, and did replace the wallpaper-only images with six 1440x900 light/dark interface shots, so the two standing blockers were re-checked and closed; the removal itself then became the blocker. All three skins' `hooks.mjs` reference identifiers that no longer exist anywhere in the file: `porco-rosso` calls `applyCardTheme()` at line 636 and `setTrack(0, false)` at line 645 with neither defined, `last-exile` calls `applyCardTheme()` at line 609 with no definition, and `white-snake` defines `applyCardTheme` at line 871 but its body assigns to `disc`, `discCore`, `tagBadge`, `title`, `subtitle`, `playIcon`, `nextBtn`, `volBtn` and `volSlider`, none of which are declared. Because every `applyTheme()` opens with `applyCardTheme()`, running each hook reproduces `ReferenceError: setTrack is not defined` (porco-rosso, aborting the rest of `apply()` including the sidebar mount), `ReferenceError: applyCardTheme is not defined` (last-exile) and `ReferenceError: disc is not defined` (white-snake, in the theme callback). The skin controller catches hook errors and keeps the static skin active, so the GUI looks fine while the wallpaper switcher, the day/night reaction and the sidebar mount are dead.
- #1659 (the claude skin, by aklnaaw) change requested. The skin itself passed review — both 1440x900 previews were inspected and show a complete, coherent light and dark theme with a full token remap, not a recolour — but two things block it. The committed market artifacts are stale: `node scripts/market-build --check` exits 1 on the PR head because `market/dist/assets/skins/claude/preview/{light,dark}.jpg` are the pre-reshoot files (30,197 and 31,205 bytes against 46,145 and 45,130 in the package), the previews having been re-shot after the last market build; regenerating changed exactly `claude.zip` and those two previews and turned the check green. And the directory bundles four self-hosted Inter, Newsreader and JetBrains Mono woff2 files (SIL OFL 1.1, which requires the copyright notice and licence to travel with the files) with no rights holder, licence name or source recorded anywhere, while the PR description states only that the skin belongs to its author; the repository's convention for bundled third-party assets is a README `Source and copyright` section, as `island-life` carries for its Animal Crossing homage, which is also where the missing Anthropic trademark and non-affiliation line belongs.
- #1658 (registering `dsh-model-priority`, by mengge237) change requested on a security finding. Every response from the plugin carries `Access-Control-Allow-Origin: *`, but its routes are registered directly on `ctx.webServer`, and the host authenticates only the `client-connection` channels and the index: `dsh-host-webserver` dispatches a matched route straight to the plugin handler. A live probe agrees — `curl http://127.0.0.1:3080/git/branches` answers 405 without a token, so the request reached a plugin handler rather than being rejected with 401. That makes the plugin's own local interfaces readable from any web page the user visits: `/dsh-model-priority/proxy-status` returns the local proxy token in `proxyBaseFor`, and `/dsh-model-priority/settings-order` and `/proxy-enable` rewrite `~/.dsh/settings.yaml`. The request asks for the wildcard header to go, the token to stop being echoed, and the settings-writing routes to be gated. Two non-blocking notes went with it: the description still says the panel hangs off `dsh-better-sidebar` while the code has used the official `settings.models.provider-card` slot since its 2026-09-10 revision, and the upstream repository is a single-commit repository created the day of the PR with no CI, tag or npm release.

Approving #1607 on the strength of its green gates and the author's report that the player removal was complete was rejected: `node --check`, `dsh-skin validate`, `skin-hooks-registry --check` and `market-build --check` verify syntax, manifests and byte hashes and never execute a hook, so none of them can see a dangling reference.

Accepting #1659's provenance as the author left it — skin copyright only, fonts unattributed — was rejected: the repository's convention for bundled third-party assets is a README `Source and copyright` section, and the OFL requires the copyright notice and licence to accompany the font files.

Re-reviewing the six carried-over PRs because time had passed was rejected: their heads are unchanged since their last review, and issuing a fresh verdict on identical code would move the review state without adding evidence.
