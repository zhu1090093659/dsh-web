### 新功能

- [scripts] 新增 pnpm dev:watch 浏览器 bundle 监听重建循环，改动触发增量重建，无需全仓构建

This release contains 4 new features, 17 bug fixes, and 16 other changes.

### New Features

- [scripts] add a pnpm dev:watch browser-bundle watch loop for change-triggered incremental rebuilds
- [dsh-web-all] remove the discontinued dsh-aionui-panel entirely; the right panel is dsh-better-sidebar's alone
- [skins] add the catppuccin v2 skin (Latte light / Mocha dark) ([#1240](https://github.com/zhu1090093659/dsh-web/issues/1240))
- [simplification] retire chat mermaid rendering, the composer file-drag inlay, and the inline side-card preference editor together with the aionui-panel removal

### Bug Fixes

- [ci] CI rebuilds the preview cohort tarball store: shallow clone at the pinned upstream commit, official-profile build, the harness's own release packer, direct packs for the experimental members, and a peers-into-dependencies manifest normalization to the self-contained shape; the store caches keyed on the workspace file hash, a cache hit is a no-op
- [ci] fix the dual pnpm specification between action-setup and the packageManager pin; the contributors workflow no longer requires the pnpm binary it never used
- [task-board] retry the roster poll across the alpha.1 service window
- [dsh-web-all] patch the morlay message-actions store require for the alpha.1 module table
- [task-board] probe the agent-preset roster actively instead of waiting for it
- [sdk] resolve the snapshot-store engine across host cohorts
- [market] keep stats and summary resilient under D1 overload
- [market] precompute the users badge count to fit the shields timeout
- [dsh-perf] drop the sidebar session row degrade CSS that pinned better-sidebar rows
- [market] serve the users badge from the edge cache with a stale fallback
- [git-graph] navigate to the new worktree session after create
- [shared] judge settings saves by read-back after the atomic write
- [remote-web-ui] honor the 0.1.2 wire contracts and structured failure codes
- [task-board] send session/list under the descriptor's _request wire key
- [dsh-ssh] restore default enablement in the aggregate and enhance the 404 guidance
- [remote-web-ui] flatten polled questions and translate the respond envelope on mobile
- [scripts] hard-close the legacy aggregate dual-publish window and guard the registry document shape

### Other Changes

- [release] pause the tag-triggered npm publish lane behind NPM_PUBLISH_ENABLED: until the cohort reaches npm, a tag push yields a GitHub Release only and npm consumers keep resolving the last published versions
- [sdk] point the official SDK cohort at the 0.1.2-alpha.1 preview: resolved from source-built tarball overrides, with manifest ranges, the engines floor, and packageManager (pnpm@11.24.0) pinned
- [sdk] re-path the cohort tarball lockfile entries to the main checkout
- [sdk] lock the cohort-resolved dependency graph
- [sdk] finish the contract pins after the remote-web-ui landing
- [sdk] clear the 0.1.2 migration debris found by review
- [sdk] drop the stale client-runtime entry from the describe-image inject
- [sdk] refresh the sync-shared copy buckets and stale apiproxy wording
- [aggregate] rebuild and commit the dsh-web-all client artifact after the dev merge
- [scripts] pin the inject contract to the 0.1.2-alpha.1 module set
- [notes] record the session-rdb stored-seed repair decision
- [notes] record the catppuccin acceptance and notion-skill merge round
- [agents] merge the CodeGraph workflow bullets and record the token-compression note
- [pre-push] align the sync and worker fixtures
- [market] regenerate dist for the catppuccin acceptance
- [readme] sync the contributor list from the GitHub API
