本版将 `@deepseek-ai/*` SDK cohort 升级至 `0.2.2-rc.3`，四个卫星仓（皮肤中心、宠物、社区插件索引、预设中心）与主仓统一发布 `0.4.19`；同时将 `dsh-agents` 小队能力迁入官方原生 Agent Teams 运行时、同步梁神预设调度器规则、移除 `dsh-message-edit` 与 `dsh-win-bash` 梁神门控，并修复任务看板鉴权、用量统计、浏览器自愈、技能目录刷新与远程中继等多处缺陷。

> **卫星仓与主仓同版本发布**：`@linxin666/dsh-client-ui-skin-center`、`@linxin666/dsh-pet`、`@linxin666/dsh-client-ui-community-plugins` 与 `@linxin666/dsh-client-ui-preset-center` 均已发布 `0.4.19`，聚合包对它们的依赖范围同步更新至 `^0.4.19`。四个卫星包现已携带插件页展示元数据（`locale/en.json`、`locale/zh.json` 与 `exports`），社区插件索引增至 137 条，市场站（`market/dist`）已随最新钉版重建。

### 升级须知

- **宿主最低版本抬升至 `0.2.2-rc.3`**：所有家族包的 `dsh.engines.dsh` 与 `@deepseek-ai/dsh` 对等依赖下限均从 `>=0.2.2-rc.2` 升至 `>=0.2.2-rc.3`。npm 上 `latest` 标签仍停在旧版，安装或升级宿主请使用 `npm i -g @deepseek-ai/dsh@next`。
- **`dsh-message-edit` 已移除**：消息编辑并重发插件及其聚合行（`web-ui-message-edit`）已从家族移除。常规通过 `@linxin666/dsh-web-all` 安装与升级的用户可直接升级（升级后不再挂载该行）；若旧 profile 中手动保留了对 `web-ui-message-edit` 或该包的显式行配置，请在升级前删除对应残留行。
- **`dsh-win-bash` 遗留配置兼容**：`syncWithLiangShen` 开关与门控已移除，`win_bash` 仅按 Windows x64 平台与随包载荷生效；旧 profile 中若仍带有 `syncWithLiangShen` 字段，会被静默忽略而不报错。

This release upgrades the `@deepseek-ai/*` SDK cohort to `0.2.2-rc.3` and ships `0.4.19` together across the four satellite repositories (skin center, pet, community plugin index, preset center) and the main monorepo. It also mounts `dsh-agents` squads onto the native Agent Teams runtime, syncs the Liangshen dispatcher rules, removes `dsh-message-edit` and the `dsh-win-bash` Liangshen gate, and fixes issues in task-board auth, usage quota calculation, browser-view CDP recovery, skill-explorer catalog refresh, and remote relay transport.

> **Satellites ship the same version**: `@linxin666/dsh-client-ui-skin-center`, `@linxin666/dsh-pet`, `@linxin666/dsh-client-ui-community-plugins`, and `@linxin666/dsh-client-ui-preset-center` are all released at `0.4.19`, and the aggregate dependencies move to `^0.4.19`. All four satellites now ship plugin-page display metadata (`locale/en.json`, `locale/zh.json`, and `exports`), the community plugin catalog grows to 137 entries, and `market/dist` is rebuilt from the updated pins.

### Upgrade Notes

- **Host floor raised to `0.2.2-rc.3`**: `dsh.engines.dsh` and the `@deepseek-ai/dsh` peer floor across all family packages rise from `>=0.2.2-rc.2` to `>=0.2.2-rc.3`. Because npm `latest` still points at an older build, install or upgrade the host via `npm i -g @deepseek-ai/dsh@next`.
- **`dsh-message-edit` removed**: the message-edit plugin and its aggregate row (`web-ui-message-edit`) have been removed from the family. Standard `@linxin666/dsh-web-all` upgrades drop the row automatically; if a legacy profile explicitly references `web-ui-message-edit` or imports the removed package, remove that stale row before upgrading.
- **`dsh-win-bash` legacy config compatibility**: the `syncWithLiangShen` option and gate are removed so `win_bash` follows Windows x64 platform and payload verification directly; legacy profile rows still carrying `syncWithLiangShen` are silently ignored without error.

### New Features and Architecture

- [sdk] Upgrade the `@deepseek-ai/*` SDK cohort to `0.2.2-rc.3` and bridge peer connection auth
- [dsh-agents] Mount squads onto the native Agent Teams runtime and switch Team mode based on the run record
- [liangshen] Sync dispatcher rules to upstream `0.72.0`, drop `spawn_teammate`, align the subagent-control catalog, optimize preset hot paths, deduplicate helpers, and harden composition
- [satellites] Align the four satellite repositories at `0.4.19`, add plugin-page display metadata, and rebuild market artifacts from the pinned commits (66 skins, 12 pets, 137 plugins, 33 presets)

### Bug Fixes

- [task-board] Inject connection auth so the trust bridge stops answering 400
- [usage] Derive quota percentage from remaining quota and probe account balance ([#2045](https://github.com/zhu1090093659/dsh-web/issues/2045) [#2047](https://github.com/zhu1090093659/dsh-web/issues/2047))
- [browser-view] Self-heal dead CDP sessions and clean Windows temporary browser profiles ([#2051](https://github.com/zhu1090093659/dsh-web/issues/2051))
- [skill-explorer] Refresh the slash-menu skill catalog after skill mutations ([#2041](https://github.com/zhu1090093659/dsh-web/issues/2041))
- [web-all] Yield narrow-screen compat drawer and backdrop to `dsh-web-mobile` ([#2050](https://github.com/zhu1090093659/dsh-web/issues/2050))
- [relay] Hand the phone identity bytes on both relay transports ([#2052](https://github.com/zhu1090093659/dsh-web/issues/2052))
- [market] Assert staged secret file mode only on platforms with POSIX permission bits

### Other Changes

- [family] Remove the `dsh-message-edit` plugin and the `dsh-win-bash` Liangshen gate
- [docs] Refresh the `publish-prep` release table with `browser-view` and mirror the external-child rule into `dsh-agents` Chinese README

- [lib] Rebuild committed `lib/` artifacts for `dsh-market` and `dsh-web-all` at `0.4.19`
