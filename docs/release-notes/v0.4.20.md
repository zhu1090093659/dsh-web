本版新增 `dsh-task-board-ssh`（任务看板的 SSH 远程执行提供方）并并入聚合家族，同时让 `dsh-ssh` 发布 `dshSsh` 服务并支持受管密钥引用；四个卫星仓（皮肤中心、宠物、社区插件索引、预设中心）与主仓统一发布 `0.4.20`。

> **卫星仓与主仓同版本发布**：`@linxin666/dsh-client-ui-skin-center`、`@linxin666/dsh-pet`、`@linxin666/dsh-client-ui-community-plugins` 与 `@linxin666/dsh-client-ui-preset-center` 均已发布 `0.4.20`，聚合包对它们的依赖范围同步更新至 `^0.4.20`。皮肤中心修复了子路径反向代理下的请求路径，社区插件索引新增六个插件。

> **兼容性**：没有破坏性变更。`dsh.engines.dsh` 与 `@deepseek-ai/dsh` 对等依赖下限仍是 `>=0.2.2-rc.3`；包名、导出面、已持久化标识与线协议均未改。`dsh-task-board-ssh` 是新增家族行，经 `@linxin666/dsh-web-all` 升级的用户会自动获得它，未安装 `dsh-ssh` 时它只在看板中提示未挂载，不改变既有看板行为。

### 新功能与架构调整

- [ssh] 发布 `dshSsh` cordis 服务供同级插件复用，并为主机增加受管密钥引用（[#2069](https://github.com/zhu1090093659/dsh-web/issues/2069)）

- [task-board] 扩展契约新增启动拦截接缝、提供方自带新卡片分区，Host 服务携带扩展注册表日志位

This release adds `dsh-task-board-ssh` (the task board's SSH remote-execution provider) to the aggregate family, makes `dsh-ssh` publish the `dshSsh` service with managed key references, and ships `0.4.20` together across the four satellite repositories (skin center, pet, community plugin index, preset center) and the main monorepo.

> **Satellites ship at the same version**: `@linxin666/dsh-client-ui-skin-center`, `@linxin666/dsh-pet`, `@linxin666/dsh-client-ui-community-plugins` and `@linxin666/dsh-client-ui-preset-center` are all published at `0.4.20`, and the aggregate's dependency ranges move to `^0.4.20`. Skin Center fixes request paths behind sub-path reverse proxies and the community index gains six plugins.

> **Compatibility**: no breaking changes. The `dsh.engines.dsh` and `@deepseek-ai/dsh` peer floor stays `>=0.2.2-rc.3`; package names, export surfaces, persisted identifiers and the wire protocol are unchanged. `dsh-task-board-ssh` is a new family row that `@linxin666/dsh-web-all` users receive automatically; without `dsh-ssh` it only reports "not mounted" on the board and leaves existing board behaviour untouched.

### Features and architecture

- [ssh] Publish the `dshSsh` cordis service for sibling plugins and add managed key references for hosts ([#2069](https://github.com/zhu1090093659/dsh-web/issues/2069))
- [task-board-ssh] New SSH remote-execution provider: pin the remote target from the create dialog, run cards on their host, in-place and git workspace strategies, remote-run detail seat and host chip
- [task-board] The extension contract gains a launch intercept seam and provider-contributed new-card sections; the Host service carries the extension registry logging seat
- [plugin-manager] Search and pagination for the built-in plugin list
- [liangshen] Deferred idle namespace reclaim without extra cache rebuilds
- [satellites] Align the four satellites to `0.4.20` and rebuild the market artifacts at the latest pins

### Fixes

- [security] Honor Host trust for proxied APIs ([#2073](https://github.com/zhu1090093659/dsh-web/issues/2073))
- [liangshen] Repair native filtering and add `keepSections` ([#2072](https://github.com/zhu1090093659/dsh-web/issues/2072) [#2071](https://github.com/zhu1090093659/dsh-web/issues/2071))
- [task-board] Skip archived sessions during reuse ([#2068](https://github.com/zhu1090093659/dsh-web/issues/2068)); reclaim a stale ledger lock whose owner cannot be identified; keep the detail action bar inside a short viewport; read a succeeded external run as a conclusion rather than an error
- [i18n] Localize Codex and fall back to English ([#2075](https://github.com/zhu1090093659/dsh-web/issues/2075))
- [web-all] Mirror the official drawer eligibility in the compat mobile contract
- [browser-view] Keep the panel reachable and clear the bare admission refusal
- [diagrams] Claim mermaid fences across both renderer banner shapes
- [ssh] Keep the sshd harness log sink open for the child's lifetime; keep the `dshSsh` provision stable across unrelated settings edits
- [task-board-ssh] Refuse sources and card addresses git would read as options, replace the installed launcher instead of rewriting it, fix the cancel path and the empty-log hole

### Other changes

- [docs] Update READMEs, package docs and `dsh-market` SEO metadata; `publish-prep` lists `dsh-task-board-ssh`
- [task-board-github] Slim the sync settings copy and compact repository rows
- [lib] Rebuild the committed `dsh-market` and `dsh-web-all` artifacts for version `0.4.20`
