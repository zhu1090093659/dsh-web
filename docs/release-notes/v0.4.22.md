本版将全仓 SDK 基线推进到 `@deepseek-ai/dsh@0.2.3-alpha.2` 并完成对应插件适配，同时带来任务看板执行内容快照与已结卡片编辑（#2080）、插件管理器按精确版本号忽略更新（#2078）、Mermaid 错误图泄漏抑制（#2084）与远程界面构建外置修复（#2082）。四个卫星仓（皮肤中心、宠物、社区插件索引、预设中心）与主仓统一发布 `0.4.22`。

> **卫星仓与主仓同版本发布**：`@linxin666/dsh-client-ui-skin-center`、`@linxin666/dsh-pet`、`@linxin666/dsh-client-ui-community-plugins` 与 `@linxin666/dsh-client-ui-preset-center` 均已发布 `0.4.22`，聚合包对它们的依赖范围同步更新至 `^0.4.22`。皮肤中心包含 `hooks.mjs` 绝对 URL 解析修复（`dsh-skins#109`）及市场内的 `remiel-starlit` 0.1.3（恢复系统降低透明度适配并清理失效选择器，`dsh-skins#110`）；社区插件索引新增 `dsh-session-color`、`dsh-sixlayer-memory`、`dsh-connectors`、`dsh-t3-inbox` 四个社区插件（索引增至 151 条）并补充投稿准入校验；宠物与预设中心为纯版本对齐。

> **兼容性与升级前提**：本版将全部工作区包的 `dsh.engines.dsh` 与 `@deepseek-ai/dsh` peer 下限由 `>=0.2.2-rc.3` 抬升至 `>=0.2.3-alpha.2`，宿主包 `engines.node` 抬升至 `^24.22.3 || >=26.13.1`。`dsh-plugin-manager` 会在自动更新前执行与官方启动门禁一致的 semver 校验，低于 `0.2.3-alpha.2` 的宿主将被拦截（`host-too-low`），请先升级 `@deepseek-ai/dsh` 宿主版本再执行插件更新。已处于 `0.2.3-alpha.2` 的用户从 `0.4.21` 升级无需数据迁移：npm 包名、聚合行 id（`web-ui-*`）、设置 section id、`/api/*` 路径、请求头与既有本地持久化键全部保持不变；已随上游移除的 `ui-settings-plugins` 裸覆盖行从 `cordis.patch.yml` 清理，避免启动告警。直接执行 `dsh web` 不运行任何迁移器（旧名 `@linxin666/dsh-web-ui-all` 到 `@linxin666/dsh-web-all` 的迁移只在 `plugin-manager` 更新任务中执行；若旧 profile 绕过更新任务，请手动把 profile 中 `@linxin666/dsh-web-ui-all` 替换为 `@linxin666/dsh-web-all` 或重装 `@linxin666/dsh-web-all`）。

This release advances the monorepo SDK cohort baseline to `@deepseek-ai/dsh@0.2.3-alpha.2` with full plugin adaptations, alongside task-board execution content snapshots and settled-card editing (#2080), exact-version update ignore rules in plugin manager (#2078), Mermaid error diagram leak suppression (#2084), and the remote-web-ui prepare-build fix (#2082). All four satellite repositories (Skin Center, Pet, Community Plugins Index, Preset Center) ship `0.4.22` together with the main monorepo.

> **Satellites ship at the same version**: `@linxin666/dsh-client-ui-skin-center`, `@linxin666/dsh-pet`, `@linxin666/dsh-client-ui-community-plugins` and `@linxin666/dsh-client-ui-preset-center` are all published at `0.4.22`, and the aggregate's dependency ranges move to `^0.4.22`. Skin Center includes the absolute `hooks.mjs` URL resolution fix (`dsh-skins#109`) and market revision `remiel-starlit` 0.1.3 (restoring reduced-transparency support and dropping inert selectors, `dsh-skins#110`); the community plugin index registers `dsh-session-color`, `dsh-sixlayer-memory`, `dsh-connectors` and `dsh-t3-inbox` (151 entries total) with a submission policy gate; Pet and Presets carry a version alignment only.

> **Compatibility and upgrade prerequisites**: All workspace packages raise `dsh.engines.dsh` and the `@deepseek-ai/dsh` peer floor from `>=0.2.2-rc.3` to `>=0.2.3-alpha.2`, and host packages raise `engines.node` to `^24.22.3 || >=26.13.1`. `dsh-plugin-manager` evaluates updates with the same semver gate as the official boot check and blocks updating hosts below `0.2.3-alpha.2` (`host-too-low`) until the DSH host is upgraded first. Hosts already on `0.2.3-alpha.2` upgrade from `0.4.21` with no data migration: npm package names, aggregate row ids (`web-ui-*`), settings section ids, `/api/*` paths, request headers and existing persistence keys stay unchanged, and the retired `ui-settings-plugins` bare patch row is removed from `cordis.patch.yml` to prevent boot warnings. > **Rolling back**: The new `promptSnapshot` / `titleSnapshot` fields on `dsh-task-board` execution records are optional and tolerated by the `0.4.21` ledger parser, and the `dsh.plugin-manager.ignored-updates.v1` browser `localStorage` key is ignored by older releases, so rolling back to `0.4.21` requires no local data cleanup. Environments staying on `0.2.2-rc.x` hosts should stay on `0.4.21`.
