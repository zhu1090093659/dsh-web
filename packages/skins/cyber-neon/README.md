# Cyber Neon — 赛博霓虹 · DSH Web UI skin

English | [中文](README.zh.md)


《赛博霓虹》— 赛博朋克终端主题：品红 × 青蓝双霓虹光球、synthwave 透视地网格与扫描线构成夜景终端场景，HUD 角标与顶部能量线强化霓虹边框；全部 --dsw-* 语义 token 重映射为品红·紫·青蓝霓虹调，暗色为浓烈霓虹版，浅色为白瓷粉彩版。

- Dark: vivid / Light: pastel, follows the active theme
- Skin-center try-on / apply supported; fully retracted on dispose
- Scene classes are declared via :global() so the injected DOM matches after build
