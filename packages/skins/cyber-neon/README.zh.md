# 赛博霓虹 (Cyber Neon) — DSH Web UI 皮肤

[English](README.md) | 中文


《赛博霓虹》— 赛博朋克终端主题：品红 × 青蓝双霓虹光球、synthwave 透视地网格与扫描线构成夜景终端场景，HUD 角标与顶部能量线强化霓虹边框；全部 --dsw-* 语义 token 重映射为品红·紫·青蓝霓虹调，暗色为浓烈霓虹版，浅色为白瓷粉彩版。

- 深色: 浓烈版 · 浅色: 粉彩版, 自动跟随主题切换
- 支持皮肤中心试穿/应用, 热插拔完全还原
- 场景裸类以 :global() 声明, 构建后由 tsdown/lightningcss 处理

## 构建

```sh
pnpm build
```
