# Aurora Nebula — 极光星舰 · DSH Web UI v2 skin

English | [中文](README.zh.md)

Aurora Nebula is a v2 pure-asset skin for DSH Web UI: cyan, indigo and violet aurora orbs, a perspective grid, deterministic stars, radar rings and HUD accents create a deep-space bridge. Dark mode is vivid; light mode is pastel.

- v2 manifest: `skin.json`
- semantic token remapping: `skin.css`
- declarative scene decorations: `patches.css` + `hooks.mjs`
- previews: `preview/light.png` and `preview/dark.png`

The skin is loaded by `packages/skins/skin-center`; it is not an independent npm package.
