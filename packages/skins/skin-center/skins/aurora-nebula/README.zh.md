# 极光星舰 (Aurora Nebula) — DSH Web UI v2 皮肤

[English](README.md) | 中文

极光星舰是一款 v2 纯资产皮肤：青、靛、紫四颗极光光球、透视网格、确定性星点、同心雷达环与 HUD 角标组成深空星舰舰桥。暗色为浓烈极光版，浅色为粉彩柔光版。

- v2 清单：`skin.json`
- 语义 token 重映射：`skin.css`
- 场景装饰：`patches.css` + `hooks.mjs`
- 预览图：`preview/light.png`、`preview/dark.png`

皮肤由 `packages/skins/skin-center` 加载，不再是独立 npm 包。
