# Cyber Neon — 赛博霓虹 · DSH Web UI v2 skin

English | [中文](README.zh.md)

Cyber Neon is a v2 pure-asset skin for DSH Web UI: magenta and cyan neon orbs, a synthwave floor grid, deterministic stars, radar rings, scanlines and HUD accents create a retro-futurist terminal. Dark mode is vivid; light mode is porcelain pastel.

- v2 manifest: `skin.json`
- semantic token remapping: `skin.css`
- declarative scene decorations: `patches.css` + `hooks.mjs`
- previews: `preview/light.png` and `preview/dark.png`

The skin is loaded by `packages/skins/skin-center`; it is not an independent npm package.
