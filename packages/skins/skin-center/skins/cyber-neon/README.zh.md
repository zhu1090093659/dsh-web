# 赛博霓虹 (Cyber Neon) — DSH Web UI v2 皮肤

[English](README.md) | 中文

赛博霓虹是一款 v2 纯资产皮肤：品红与青蓝霓虹光球、synthwave 透视地网格、确定性星点、雷达环、扫描线与 HUD 角标组成复古未来终端。暗色为浓烈霓虹版，浅色为白瓷粉彩版。

- v2 清单：`skin.json`
- 语义 token 重映射：`skin.css`
- 场景装饰：`patches.css` + `hooks.mjs`
- 预览图：`preview/light.png`、`preview/dark.png`

皮肤由 `packages/skins/skin-center` 加载，不再是独立 npm 包。
