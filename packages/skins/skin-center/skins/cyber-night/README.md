# @linxin666/dsh-skin-cyber-night

English | [中文](README.zh.md)

Cyber Night (赛博夜城) — a cyberpunk night-city skin for the dsh web GUI,
shipped as a pure asset directory inside the skin-center package.

## What it is

- **Pure assets**: `skin.json` (v2 manifest) + `skin.css` (token remap) +
  `patches.css` (component patches) + `assets/` (night-city backdrop art,
  neon favicon) + `preview/` (light/dark screenshots). No package.json, no
  build step; the skin-center package is the only loader.
- **Backdrop**: the neon cityscape is declarative via
  `contributes.backgroundMedia` (light/dark scrims), owned by the
  skin-center background control.
- **Token-first**: light values on `:root`, dark values under
  `body[data-ds-dark-theme]`; the loader scopes every selector under
  `html[data-dsh-skin="cyber-night"]`. Cyan family replaces the
  blue/deepseek tokens, magenta/purple accent, neon yellow warn.
- **Hooks**: `hooks.mjs` injects the neon favicon and retracts it on
  cleanup.

## Preview

```sh
pnpm market:build                              # refresh market/dist
open market/dist/preview.html?skin=cyber-night&theme=light
```
