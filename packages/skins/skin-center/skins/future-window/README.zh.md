# 云轨舱窗

[English](README.md) | 中文

云轨舱窗是 dsh Web GUI 的昼夜双主题皮肤，将工作区呈现为俯瞰未来城市的安静舱室。

## 能力

- 使用独立的昼景和夜景图片，并分别匹配冰蓝与深海军蓝 token 配色。
- 将任务看板、SSH 和技能中心保留为原生可交互的三行入口，统一放在一块猫耳织物软枕上。
- Workspace 及以下区域保持 Web UI 原生外观和布局。
- 以纯 v2 资产目录交付，不含独立包、构建步骤、可执行 hook、服务、事件或模型请求集成。

## 安装

发布后，在 DSH 创意工坊按需安装云轨舱窗，再到“设置 > 皮肤中心”选择该皮肤。

本地开发时，将本目录复制到 `$DSH_HOME/skins/future-window/`，刷新页面后在皮肤中心选择云轨舱窗。

## 配置

亮色和暗色配色通过 `skin.css` 重映射官方 L1 token。`patches.css` 是已声明的高敏感 L3 样式，用于侧边栏、新会话按钮、三行启动入口、响应式背景构图和软枕装饰图。

Wallpaper Engine 和用户手动选择的背景优先于皮肤背景；皮肤中心的背景遮蔽和模糊控制仍然可用。

## 预览

提交的 `preview/light.jpg` 和 `preview/dark.jpg` 使用仓库市场试穿模拟器及 `node scripts/capture-previews future-window` 生成。

## 安全与隐私

本皮肤仅包含 CSS 和本地图片资产，不包含 `hooks.mjs`，不发起网络请求，不读取会话正文，不发送事件，不注册服务，也不修改模型请求。

## 已知限制

- 软枕构图依赖当前侧边栏结构，因此按规范作为 L3 样式明确披露。
- 只有安装对应的任务看板、SSH 和技能中心入口后，才会显示增强后的入口效果。
- 移动端会调整背景焦点；侧边栏折叠时隐藏软枕。
