# 万象镜

[English](README.md) | 中文

一套 dsh 皮肤：**每次打开都是一张不同的二次元插画**，来自一个第三方随机图接口，
界面只在它上面留一层玻璃。皮肤没法挑「配得上这张画」的颜色——它不知道来的是哪张画——
所以设计预算放在**壳**上：一层中性遮罩、一条棱镜色、两根渐隐到零的侧栏。

## 这是什么

- **纯资产**：`skin.json`（v2 清单）+ `skin.css`（完整的 `--dsw-alias-*` token
  重映射）+ `patches.css`（L3 自由选择器）+ `hooks.mjs`（受信任的逃生舱）+
  目录内 4 个生成的 SVG。无 `package.json`、无构建步骤。
- **壁纸不在这个目录里**：运行时从 `https://api.elaina.cat/random/` 取。那个服务的
  任何内容都没有随本仓库分发——见下面的「第三方内容」。

## 为什么壁纸地址只能由 hooks 注入

两条 fail-closed 的墙，都对着已发布的代码验过：

1. `contributes.backgroundMedia.src` 必须是皮肤目录内的路径
   （`core/manifest-v2/validate.ts` 的 `checkRelPath` 拒绝任何协议 URL）。
2. 样式表里的远程 `url()` 是**整张表**被拒。实测：把远程 URL 写进 `patches.css` 之后

   ```
   GET /api/skin-center/v2/skins/kaleido/patches
   HTTP 422  {"error":"css-whitelist-violation",
              "violations":["patches.css: remote URL \"https://…\" is not allowed;
                             ship the asset in the skin directory"]}
   ```

   浏览器一条规则都收不到，而界面上没有任何提示。所以地址由 `hooks.mjs` 以
   内联自定义属性（body 上的 `--kl-art`）注入——白名单管不到 JS 写的内联样式。

## 加载的那两秒里屏幕是什么

在真实界面上量过（用 `Page.addScriptToEvaluateOnNewDocument` 装的逐帧采样器，
一次刷新）：

```
首个 paint 72ms · 外壳启动 · hooks 写入 --kl-art 744ms
随机图下载 764→1878ms · 壁纸画出 1889ms
```

也就是说那张画最早 ~1.9s 才可能存在，**在这之前铺什么，读者都会读成「默认背景」**。
所以加载态铺的是一块素底（跟着明暗走的颜色），而不是任何图案；棱镜底片从「加载画面」
降级成「失败画面」：只有 `hooks.mjs` 连错三次、打上 `data-kaleido-plate` 之后才铺。
正常刷新的路径是「素底 → 画」，首张也不走淡入。

换到**下一张**是真交叉淡入——旧画先垫到 `body::before`（`--kl-prev`），新画在它上面
淡入，所以没有一帧是只有底色的。

## 壳

- 两根侧栏是**一条往中间渐隐到零的纱**，不是板：左边压得住字，右边把画让出来，
  壁纸从最左边一直连到最右边（「工作区」那一栏也是透的）。
- 任何一根侧栏都不挂 `backdrop-filter`：那会让它成为 `position: fixed` 后代的包含块，
  而设置弹窗就渲染在侧栏子树里。真正的模糊只给叶子——输入卡与浮层。
- 一条紫→青的棱镜色只出现在焦点上：CTA、光标、焦点环、输入卡的描边与它那两个取景框。

## 轮换

每张画都是**先预载、再上屏**，所以不会在半张图上完成切换。

| 触发 | 间隔 |
| --- | --- |
| 定时 | 4 分钟 |
| 页面加载 / 切换皮肤 | 每次都换（用 `?v=` 劈开缓存） |
| 标签页离开超过 45 秒后回来 | 回来时换一张 |
| `Ctrl+Alt+K` | 手动（2.5 秒冷却） |

压在真实壁纸上的对比度（采样渲染后的像素）：正文 7.8–13.4:1、侧栏 7.8–13.4:1，
门槛 4.5。

## 第三方内容

壁纸来自一个**第三方随机图接口**（`https://api.elaina.cat/random/`）：每次请求返回
一张任意插画，其来源与授权本皮肤无法核实。仓库里不分发任何图片——图片由浏览器在运行时
逐张取回——但这条依赖值得评审时单独权衡。接口不可用时皮肤退回自己的棱镜底片，
所以界面不会渲染成空白。
