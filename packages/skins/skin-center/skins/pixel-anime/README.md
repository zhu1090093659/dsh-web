# Anime Pixel (二次元像素)

English | [中文](README.zh.md)

A dual-theme dsh skin in **16-bit pixel-art language**: the same stretch of coast at
two times of day. Daylight is a palm beach — warm sand, a wet-sand tide mark,
broken foam lines, a turquoise-to-deep sea, a stepped sun with eight rays and four
pixel clouds. Night is a starfield over the water — a crescent moon, a Milky Way
arch built out of dim dots, and a moonlit beach.

Nothing here is a gradient ramp: shading is stacked with an 8px checkerboard
dither, because pixel art has no smooth ramps. Every corner is square (pixel art
only has right angles and 45 degrees), and every card carries a 2px sprite keyline
plus a 4px hard, unblurred drop shadow.

## What it is

- **Pure assets**: `skin.json` (v2 manifest) + `skin.css` (full `--dsw-alias-*`
  token remap) + `patches.css` (L3 free selectors) + generated SVG sprites.
  No package.json, no build step, no hooks.
- **Drawn, not gradient-assembled.** The coconut palms, starfish, shells, grass
  tufts, clouds, seagulls, footprints, crescent moon and starfield are generated
  SVGs (`pixel-plate.mjs` in the authoring repo), each written as character art
  where one pixel is one character. Low-resolution *shapes* cannot be expressed
  with gradients — trying produces a smear of diagonal stripes.

## Where the coast lives

The whole scene is one layer on `body::after` (position: fixed; inset: 0). The
hero (empty-conversation) element paints **nothing** — the shell's base coat
(`bg-base`) is fully transparent, so the canvas shows through at full strength and
the home screen and a real conversation see the same picture.

The shoreline is anchored to the **bottom edge**, not to a percentage of the
height: sand 286px, sea 134px, so the horizon sits 420px above the bottom, and the
props are placed against that same line. `background-position: calc(100% - Xpx)`
pins the image's *bottom* edge X px above the container's bottom — reading X as a
top offset puts the whole sea 58px above the sand and leaves a strip of sky in
between.

## Palette

Twelve declared colours per mode expand into all 95 official semantic tokens.

| | Light — day | Dark — night |
| --- | --- | --- |
| canvas / panel | `#F5E3BE` / `#FFFCF4` | `#050A18` / `#0D1530` |
| ink / muted | `#0B1D26` / `#45564D` | `#F2F7FF` / `#A2B4D4` |
| brand / accent | `#0F7182` / `#E8783C` | `#57B6F0` / `#E0A6FF` |

Body-vs-panel contrast: 16.82:1 light, 16.73:1 dark (threshold 4.5:1).

The night sky is deliberately **not pure black** — a silhouette on pure black is
not a silhouette — so it keeps a band of airglow, and the night sand is mixed with
a little moonlight warmth so it reads as brighter than the sky.

## Chrome

- **Sidebar**: folder rows are sand plates with a 3px ink edge; the selected row
  carries a dithered foam line along its bottom edge (the same trick as the
  shoreline); the New Session button is a miniature horizon by day and a small
  patch of night sky with nine scattered stars by night.
- **Composer**: a dithered card with a foam line at its foot, keylined toolbar
  buttons, a sunset-orange send button (galaxy violet at night), and an accent
  caret.
- **Conversation rows**: the user's message is a sand postcard with a foam
  underline; tool/command rows share that same **opaque** fill (the engine's
  default is `alpha(raised, 0.7)`, which lets the coast bleed through) plus a 3px
  accent edge.
- **Nothing sits between the background and the content**: `glassBase: 0` makes
  `--dsw-alias-bg-base` fully transparent in both modes (`#f5e3be00` /
  `#050a1800`). The default value stacks three translucent coats (html, body,
  AppFrame) that hide 96.7% of the canvas — measured, only 9% of the coast reached
  the conversation column before this.

## Backgrounds you add yourself

The canvas yields: `body[data-dsh-wallpaper-active]::after` and
`body[data-dsh-backdrop-active]::after` clear the layer entirely, so a wallpaper or
backdrop of your own is never painted over.

## Install

Copy this directory to `$DSH_HOME/skins/pixel-anime/` and select it in the skin
center, or install it from the market.
