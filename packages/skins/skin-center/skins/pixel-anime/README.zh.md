# 二次元像素

[English](README.md) | 中文

双模式的 dsh 皮肤，画法是**十六位像素画**：同一片海岸的两段时间。白昼是椰影沙滩
—— 暖沙、湿沙的水痕、断成几截的浪线、近岸泛青到远处发深的海，一颗带八条光芒的阶梯
太阳和四朵点阵云；深夜是水上的星野 —— 一枚下弦月、一条由淡点堆出来的银河拱，以及月光
照亮的滩涂。

这里没有一处是渐变 ramp：明暗是 8px 一格的**棋盘抖动**堆出来的，因为像素画里没有平滑
ramp。所有圆角归零（像素画只有直角和 45 度），每张卡片一圈 2px 精灵描边加 4px **不带
模糊**的实心投影。

## 这是什么

- **纯资产**：`skin.json`（v2 清单）+ `skin.css`（完整的 `--dsw-alias-*` token
  重映射）+ `patches.css`（L3 自由选择器）+ 生成的 SVG 精灵。无 package.json、
  无构建步骤、无 hooks。
- **画出来的，不是拼渐变拼出来的。** 椰子树、海星、贝壳、草簇、云、海鸥、脚印、下弦月
  与星野都是生成的 SVG（作者仓库里的 `pixel-plate.mjs`），每一张都是字符画，
  一个像素就是一个字符。低分辨率的**形状**没法用渐变表达 —— 硬拼只会得到一坨斜条纹。

## 海岸画在哪

整幅画是 `body::after` 上的一个图层（position: fixed; inset: 0）。首屏（空会话那一页）
**什么都不画** —— 机壳底色 `bg-base` 是全透明的，画布原样透上来，所以首页和真实会话页
看到的是同一幅画。

海岸线锚在**底边**上，而不是高度的百分比：沙 286px、海 134px，海平线因此落在底边上方
420px，所有道具都摆在这条线上。`background-position: calc(100% - Xpx)` 钉住的是图片的
**下缘**离容器底边 X px —— 把 X 当成「上缘高度」来写，整条海会浮到沙线以上 58px，
中间露出一道天空。

## 配色

每个模式声明 12 个颜色，展开成全部 95 个官方语义 token。

| | 浅色 · 白昼 | 暗色 · 深夜 |
| --- | --- | --- |
| 画布 / 面板 | `#F5E3BE` / `#FFFCF4` | `#050A18` / `#0D1530` |
| 墨 / 次要 | `#0B1D26` / `#45564D` | `#F2F7FF` / `#A2B4D4` |
| 主色 / 强调 | `#0F7182` / `#E8783C` | `#57B6F0` / `#E0A6FF` |

正文 / 面板对比度：浅色 16.82:1，暗色 16.73:1（阈值 4.5:1）。

夜空**刻意不是纯黑** —— 剪影压在纯黑上就不叫剪影 —— 所以留了一档空气辉光；夜里的沙掺了
一点月光的暖，让它明显亮于夜空。

## 机壳

- **侧栏**：文件夹行是带 3px 墨边的沙台；选中行的下缘压一道抖动白边（和岸边同一个手法）；
  「新会话」按钮白天是一块微缩海平线，夜里换成一小块夜空加九颗疏落的星点。
- **输入卡**：卡面带沙点、下缘一道碎浪，工具条按钮补了精灵描边，发送键是落日橙
  （夜里银河紫），光标也染成强调色。
- **会话行**：用户消息是一张沙色明信片，下缘压碎浪；工具 / 命令行与它共用同一个
  **不透明**底色（引擎默认是 `alpha(raised, 0.7)`，海岸会透上来），另加左侧 3px 强调色边。
- **背景与内容之间不留任何一层**：`glassBase: 0` 让 `--dsw-alias-bg-base` 在两个模式里
  都是全透明（`#f5e3be00` / `#050a1800`）。默认值会在 html / body / AppFrame 上叠三层
  半透明底、盖掉 96.7% 的画布 —— 实测改动前只有 9% 的海岸能透到会话列。

## 你自己挂的背景

画布会让路：`body[data-dsh-wallpaper-active]::after` 与
`body[data-dsh-backdrop-active]::after` 会把这一层整片清空，所以你的壁纸或背景板
永远不会被盖住。

## 安装

把本目录复制到 `$DSH_HOME/skins/pixel-anime/`，然后在皮肤中心里选中它；
也可以直接从市场安装。
