# 鲸鱼娘·望海 (Whale Girl · Sea Gaze)

[English](README.md) | 中文

双主题皮肤，建在**一对配套插画**上：浅色是日光下的海岸，深色是把同一场景重新打光成月夜深海。
界面走赛璐璐／动画的画法——平涂、墨线、硬投影——但每一块面都是半透明的「白纱」，
所以插画始终在面板后面看得见。

## 构成

- **纯资产**：`skin.json`（v2 清单）+ `skin.css`（完整重映射 `--dsw-alias-*`）
  + `patches.css`（L3 自由选择器）+ 生成的 SVG 与两张背景画。没有 package.json、
  没有构建步骤、没有 hooks。
- **成对的两张背景**：`assets/whale-day.webp`（源图 2715x1500，发行 2560x1414）与
  `assets/whale-night.webp`。两张构图相同，所以按白昼调好的布局在夜里同样成立。
  两张都**不做调色**：它们本来就是画好的一对，给其中一张重新打光只会把「一对」弄坏。
- **面板是纱，不是墙**：接管渲染器自带的面 —— 侧栏、详情栏、输入卡、工具／上下文行
  全部改成「有色玻璃 + 实心墨线」。叠在插画上的同色 coat 在浅色压到 0.16，深色整层移除。

## 三种海的纹样

只有三种，且都是**画**出来的，不是滤镜：

- **蕾丝网眼** —— 两组错开半个周期的点阵，铺在每块面上。单向点阵读作灰阶或纱窗，
  两组交错才读作网纱。
- **青海波** —— 两层错开的半圆浪线，`repeat-x`，**只做边**（侧栏底缘、首屏底缘）。
  这套皮的纹样只有「面」与「边」，不铺满整个视口：早期版本把浪铺满首屏，
  插画当场消失在一张鱼鳞壁纸下面。
- **上升气泡** —— 生成的 SVG 贴图，挂在加载器自己的背景层上，两层不同瓦片尺寸跑出视差。
  动的是 `background-position`，所以循环天然无缝。

## 几处界面

- **字标** —— 官方那条内联 SVG 字标藏掉，换成两段式：`DSH`（小号、拉开字距、退成灰）
  + 品牌渐变的名号，中间一根细线。官方鲸鱼纹章用 CSS `fill` 上色 —— DSH 的标志本来就是鲸鱼，
  正好和画里那只玩偶同色。
- **工作区行** —— 每行一块淡蓝牌照；展开中的那一个再实一档并在左缘压一根鲸蓝。
- **新会话** —— 不再是官方那颗白药丸，而是一张牌：深海渐变 + 白浪脚 + 白鲸
  （贴纸当 `mask-image` 用，所以和别处的鲸是同一份图形）+ 白纱环。浅色换成海玻璃版本、深蓝字。
- **代码框** —— 浅色走纸白（底越白，shiki 那套按白底设计的浅色语法色对比度越高），
  深色走深海的一格。

## 可读性

对比度按**合成之后**的底实测（插画 + scrim + 纱 + 面板都在）：把文字藏掉、截图、在同一批
矩形里取底色算 WCAG。

- 正文：浅色 30 段最低 4.67:1，深色 7.14:1，**0 段低于 4.5**；
- 侧栏工作区名：浅色 7.52:1，深色 8.58:1；
- 工具调用行：浅色 6.67 / 5.41:1，深色 7.47 / 5.43:1。

Markdown 表格单独给了一块薄面 —— 表格单元格自己没有面，是唯一「压到画作较暗处」而掉线的地方。
