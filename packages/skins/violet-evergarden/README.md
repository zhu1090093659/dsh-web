# Violet Evergarden Skin

English | [中文](README.zh.md)

A hot-pluggable dsh web GUI skin based on the installed Wallpaper Engine Violet Evergarden preview (`3022080536`). It uses ivory, ink gray, cool blue-gray, and a restrained vermilion accent sampled from the original artwork.

The package embeds the extracted original 6208 x 3520 background, transparent subject, effect masks, and non-audio scene parameters. WebGL reproduces the original masked water-wave and shake passes. The upper bars retain their static composition without audio response, and the wallpaper does not react to pointer movement.

```sh
dsh plugin --profile web add @linxin666/dsh-skins
dsh-skin use violet-evergarden
```
