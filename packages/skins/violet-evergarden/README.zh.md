# 紫罗兰永恒花园皮肤

[English](README.md) | 中文

一款可热切换的 dsh Web UI 皮肤，基于本机 Wallpaper Engine 紫罗兰永恒花园预览图（`3022080536`），使用从原画提取的象牙白、墨灰、冷灰蓝和少量朱红半透明面板。

包内嵌入解包后的原始 6208 x 3520 背景、透明主体、效果遮罩和非音频场景参数。WebGL 按原参数重现局部水波与摆动效果。顶部柱状层保留静态构图，不响应音频，壁纸也不会响应鼠标移动。

```sh
dsh plugin --profile web add @linxin666/dsh-skins
dsh-skin use violet-evergarden
```
